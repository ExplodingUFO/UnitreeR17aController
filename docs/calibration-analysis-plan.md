# 录制分析与参数优化方案

日期：2026-11-22。本文是实现设计，尚未加入运行程序。控制页录制与日志历史已在 `d8b1308` 提交。

目标是让使用者录制一次运动后，程序自动找出异常片段、说明判断依据，并给出下一步可验证的优化操作。先完成数据诊断与前后对照，再依据足够的数据生成参数候选。全部计算在本机 Rust 中完成。

## 1. 使用流程

1. 在控制页选择时长并录制，继续使用现有点动按钮操作。
2. 记录写入完成后，点击“分析”；也可勾选“录完分析”。
3. 在同一弹窗查看“概览、曲线、优化”三个页签。
4. 程序指出问题涉及的关节、时间段和指标，给出优化建议或需要补录的条件。
5. 选取另一条记录作为基线，比较改善幅度和新增问题。
6. 有可用参数候选时，点击“填入参数”，进入现有参数弹窗草稿；仍通过原有“应用”操作生效。

“录完分析”只读取已完成的记录。分析不申请控制权，不启动动作，不修改运行参数。打开或关闭分析弹窗不取消现有录制。

控制页保持当前紧凑布局，不增加常驻参数区。入口放在“记录”弹窗：列表保留开始时间、时长、状态、样本/丢弃摘要和“分析、下载”。完整写入计数放在记录详情。分析弹窗在 800×560 内容区内滚动；页签与关闭按钮固定，曲线和参数建议分别显示。宽屏可在曲线旁显示所选问题的依据。

## 2. 一段记录能回答什么

| 检查对象 | 自动计算 | 输出及后续操作 |
| --- | --- | --- |
| 数据完整性 | 每轴有效覆盖、长缺口、丢弃与写入错误、使能/模式变化 | 标出可分析片段与缺失字段；不足时列出补录条件 |
| 参考轨迹 | 速度、加速度、jerk、起停和方向变化 | 定位参考本身的突变；与实际发送、反馈分开显示 |
| 实际发送 | TX 间隔、主机写入耗时、源参考年龄、位置积分一致性、编码差 | 定位发送不连续、量化与时序异常；重复 seq 不直接算重复目标 |
| 关节跟随 | 位置误差、速度起伏、停滞后追赶、方向相关偏差 | 排列受影响关节和片段；结合参考与发送判定异常出现在哪一层 |
| 回传速度 | 设备 dq 与位置趋势估计速度的差异 | 区分速度字段异常与位置轨迹也有波动的情况 |
| 周期波动 | 有效片段的频谱峰、频带能量、多个窗口的一致性 | 给出可分辨频带及证据；时序不足时不生成陷波参数 |
| 驱动状态 | 最早记录到的 error、timeout、模式退出及电压变化 | 显示其与软件 Disabled 报文的先后顺序，不把未记录的首个故障补成结论 |
| 参数使用 | 配置版本、Kd、速度前馈权重、摩擦项与限幅占比 | 分开评价每组参数，避免将多个版本混成一个平均值 |

诊断分成“已检测现象”和“解释假设”。例如，可以确定“恒速目标期间，J2 位置趋势反复接近停滞后追赶”；“摩擦与伺服响应相互作用”需要正反向与参数对照支持。程序显示依据、成立条件和下一项测试，不输出无依据的百分比置信度。

单段记录先做定位，不要求它同时完成摩擦、惯量、重力和 PD 增益辨识。没有有效稳态段时，报告起停行为，不生成恒速标定结果。

## 3. 时间与数据处理

### 三类时间序列保持独立

`control` 是控制周期中的参考与缓存反馈，`transmit` 是发送时对齐后的目标，`feedback` 是逐包回传。分析以新到达的逐轴反馈为观测，不把多次 control 中复用的同一个反馈计成多个独立样本。

- 保留文件顺序与原始时间；分析副本按来源和关节整理。相同时间的样本保留顺序，倒序、重复和缺口单独计数。
- 用 generation、运动类型、axis、方向、stopping、enabled、模式和参数版本划分片段。不同参数、起步、恒速、减速、保持与反向分别计算。
- `seq` 仅关联源控制周期；同一 seq 可以对应不同发送目标。编码差使用对应批次的理想值和 wire 值。
- 每条 RX 对最近已完成的 TX 批次作主机时间匹配，保留批次时间跨度和参考年龄。它是近似配对，不是电机实际采样时刻的恢复。

当前 TX 时间是七轴批次开始时间，`write_us` 是主机写调用耗时；RX 时间在读取后逐包赋值。文件没有设备采样时钟、逐轴上总线时刻或驱动执行确认。因此精确相位、机械延迟与闭环频响不能仅由当前主机时间戳确定。

### 求导、重采样与频谱

先识别同轴接收成簇、微秒级到达和长缺口。位置趋势采用实际时间上的局部多项式拟合；接收成簇时可取每簇最后一包形成低带宽趋势，并保留原始包。禁止直接用微秒级接收间隔差分为机械速度。

报告同时提供原始 dq 和固定窗口的位置速度估计；用多种预先规定的窗口检查结论是否一致，所有记录使用同一分析配置。滤波只用于离线测量，不进入控制或改变导出原始值。长缺口不插值，缺口两侧分别分析；跨轴数据只在共同有效区间比较。

只有覆盖和时序满足条件的片段才重采样。降采样前低通，明确采样率、通带、窗口、去趋势方式、有效时长和缺口处理。频谱使用加窗分段平均；频率间隔约为 `1/T窗口`，零填充不增加实际分辨能力。短片段或接收缓冲主导的片段只给趋势统计，不据此推荐陷波器。

### 指标定义固定

- 位置误差保留有符号偏差、RMS、绝对误差 p95；同时说明目标取自哪一层以及配对方式。
- 稳态速度起伏使用去除局部趋势后的绝对 RMS，并保留绝对单位。接近零速时不使用除以平均速度的百分比。
- 跟随误差与未缩放的运动目标 `dq_ref` 比较；编码误差与 `dq_feedforward` 比较。降低速度前馈权重不能通过降低评价目标获得更好分数。
- 每个指标记录有效时长、样本数、剔除原因和时间加权方式；原始值与延迟估计后的辅助值分开显示。恒速段无法区分固定时间延迟与固定位置偏差时，延迟输出为空。
- 关节指标覆盖七轴。TCP 指标需要模型、TCP 变换与共同时间上的关节估计；缺少这些条件的旧文件仅做关节分析。

## 4. 优化建议如何生成

按异常出现的位置选择操作，不对所有情况统一加滤波或提高 Kd。

| 证据组合 | 优先建议 | 验证方式 |
| --- | --- | --- |
| 参考已有速度/加速度不连续，发送跟随变化 | 检查参考生成、切换与现有 jerk 限制 | 对比相同操作的参考连续性、路径和停止时间 |
| 参考平滑，发送位置变化不连续 | 检查发送时序、对齐与编码量化 | 检查实际 TX 的增量、间隔及跟随变化 |
| 设备 dq 起伏，位置趋势基本平滑 | 检查速度估计、接收成簇与量化 | 比较位置趋势与 dq，先保留现有控制参数 |
| 目标平滑，位置也反复停滞/追赶，方向相关 | 优先标定已有平滑摩擦补偿 | 同姿态、同路径下正反向、多档速度对照 |
| 在可靠时序和多段数据中出现重复频带，参考没有该波动 | 识别伺服/结构响应；安排 Kd 与前馈对照 | 同时检查相邻轴、静止、跟随误差和停止效果 |
| 错误、模式退出、限幅或电压异常与波动重合 | 先处理驱动状态与输出受限问题 | 查清首个记录到的异常，再进行参数对照 |

报告中的建议包含操作对象、理由、适用条件、下一次采集要求和评价指标。已有证据只支持补录时，就输出补录计划，不填写假参数。

## 5. 参数候选与标定

### 先适配已有摩擦模型

保持当前模型 `τfriction = Fc × tanh(v/ε) + B × v`。首轮固定 ε，估计逐轴 Fc 与 B；不同时搜索全部参数。模型辨识中的 v 取可用的实测速度趋势，部署前再用当前实现的参考速度输入检查同一模型，低速过渡处要单独验证。

在同姿态附近采集正反向、多个可分辨速度的恒速段，去除起停与明显耦合段。若有可校核的关节侧力矩估计和重力/惯性预测，构造力矩残差，并用 `b + Fc × tanh(v/ε) + B × v` 拟合；b 用来暴露该局部姿态中的偏置，不能直接作为额外保持力矩应用。

使用小规模约束最小二乘、鲁棒权重和分列尺度归一化；以 SVD 检查秩和条件数。Fc/B 受现有输入范围及使用者确认的逐轴试验范围共同约束。按完整时间段或整次录制留出验证，不随机拆分相邻点。输出拟合残差、留出误差、参数相关性、适用速度与姿态范围。约束边界是否激活单独显示；处于边界的拟合结果需要结合留出误差判断。

单一窄速度段、零速附近 `tanh(v/ε)≈v/ε`、未知负载或力矩来源不明确时，Fc/B 可能无法分别确定。`tau_ff` 是程序施加值，不能用它回归并证明自身补偿有效；驱动 tau 也不是独立外部力矩传感器。条件不足时仍可分析位置波动，并给出小范围参数对照方案，不生成已标定系数。

### Kd 与速度前馈采用实际对照

当前接口是 PD＋前馈，没有 Ki；现有调试仅暴露 Kd、速度前馈与摩擦参数。Kp 保持现有实现。软件输入范围不作为机械臂的已验证试验范围。

Kd 与速度前馈候选要通过同条件的实际运动评价。第一轮不执行自动 Kd 扫描，尤其不把“继续增大 Kd”作为消抖通用操作。使用者在参数弹窗确认单轴、单项候选，程序负责对照记录、指标计算、排序和保留上一组参数。

每次只改变一项，先验证单轴关节点动，再验证末端点动所涉及的七轴响应。摩擦候选还要在关闭补偿与启用补偿之间比较；保持、正反向、不同速度和停止均要覆盖。TCP 旋转中心、路径、停止和收纳逻辑保持现状。

## 6. 自动比较怎样判定改善

比较前核对左右臂、模型/标定版本、TCP、安装方向、负载说明、初始姿态、运动空间、坐标系、方向、速度与片段类型。不同条件可以并排查看，不能直接显示“改善百分比”。

在共同的速度与姿态范围内，分别报告基线和候选的：

- 速度起伏 RMS 与位置误差 p95；
- 反向偏差、超调和停止后稳定时间；
- 七轴相邻响应、TCP 路径偏差（条件齐全时）；
- 输出限幅、故障/模式退出、供电与温度变化。

先检查故障、输出受限、跟随和停止是否恶化，再比较主要波动指标。不把各项揉成一个不透明总分；“改善/接近/变差”的阈值来自重复基线测量的波动范围和使用者的验收目标，不预设硬件精度。候选只有在重复对照和留出条件下仍表现较好时才标为推荐；单次比较显示本次结果。

离线重放可以验证算法、编码、限幅、缺失数据处理和候选计算是否一致，不能证明修改参数后的真实闭环响应。

## 7. 现有数据与必要补充

现有记录已足够实现关节诊断：三类来源、逐轴位置/速度/力矩估计、TX 理想值与编码值、P/D、模式与故障、参数版本及前馈分解。现有 `analyze_trace` 输出间隔、参考峰值、control 缓存反馈 RMS 和编码差，可以保留为基础摘要。

为使后续 TCP 分析和前后对照可复现，新录制需要补充：

- 文件格式版本、应用/算法版本、模型与标定内容摘要；
- 实际使用的基座重力方向、Link7→TCP、运动空间/坐标系/请求速度；
- 参数及运动上下文变更的时间和版本；
- 使用者填写的安装与负载说明，以及基线/候选关联。

上述信息在开始录制或上下文变化时记录，不在每个控制周期序列化字符串或读取磁盘。上下文缺失时对应分析项标为缺少条件；不从旧文件猜测 TCP 或负载。日志事件只能按墙钟与采样开始时间作辅助关联，故障分析以录制内 TX/RX 单调时间顺序为主。

## 8. 代码组织与运行方式

只新增一个集中计算的 Rust 文件 `src-tauri/src/analysis.rs`，内部完成校验、分段、时序整理、指标、诊断、候选和比较；不为每种指标拆一个模块。核心入口接收录制数据与分析选项，返回结构化报告，不接收 `ArmHandle`、串口或数据库句柄。

现有 CLI 改为读取文件并调用同一计算入口；保留原有摘要字段及统计含义，新观测指标单独命名。解析与旧格式兼容集中处理，避免桌面与 CLI 各算一套。当前 example 不在图索引范围内，本设计已直接核对其源码。

后台任务接在现有 server/journal/trace 的读取和持久化流程中。最多同时计算一项，重复请求同一输入与算法版本复用结果。计算使用专用后台任务，阶段间可取消；大数组读取、排序、拟合与报告写入均不进入控制线程，也不长期持有采样队列锁。首次只分析已有完整录制，CLI 继续支持导出的 JSON 文件。

报告保存输入内容摘要、算法版本、选项、有效片段、指标、问题依据和候选。报告与对应录制保留关联并随录制清理，支持导出；分析先取得独立输入副本，保存前复核来源。来源已清理时返回明确状态，不把结果挂到其他记录。关闭弹窗可继续计算；应用退出取消未完成任务，重开后已完成报告可读取。

拟增加两个只读分析用途的请求（尚未实现）：

| 请求 | 输入 | 输出 |
| --- | --- | --- |
| `POST /v1/traces/{id}/analysis` | `{baseline_trace_id?:string}` | `202 {analysis_id,status}`；基线可省略 |
| `GET /v1/analyses/{analysis_id}` | 无 | 状态、进度阶段及完成报告 |

沿用应用令牌，无需控制权。输入错误、采样尚未完成、来源已清理、计算忙碌分别返回明确错误；完成的同一输入复用缓存。接口不接受任意文件路径，也不提交控制命令。UI 通过报告把候选填入现有草稿，实际应用仍走 `configure_servo` 及其确认流程。

报告结构集中为 `quality / segments / metrics / findings / candidates / comparison / provenance`。每条 finding 关联轴、时间段、证据指标、解释类型和建议；candidate 附完整配置、来源、适用范围与验证状态。默认只返回摘要与适量曲线点，原始采样仍通过已有下载接口获取。

## 9. 实现顺序与验收

第一步交付“自动分析＋曲线＋对照报告”，能明确指出发送、反馈、驱动状态中的异常。第二步在这些指标稳定后加入已有平滑摩擦模型的候选拟合。Kd/速度前馈先支持使用者指定候选的自动比较，不在第一步增加在线自适应或自动激励。

离线验收覆盖：

- 理想平滑、参考突变、发送阶梯、速度量化与位置量化；
- RX 成簇、重复时间、乱序、缺帧、长缺口和七轴异步；
- 速度字段异常而位置平滑，以及位置本身有停滞/追赶；
- 配置切换、起停与反向分段、故障发生与 Disabled 的先后；
- 已知参数的合成摩擦数据、不可辨识数据、限幅与时间块留出；
- 降低速度前馈不降低评价目标、候选比较条件不一致时不误报改善；
- 旧格式、来源清理、重启后报告恢复、后台取消和并发负载；
- 从分析到填入草稿不下发动作，应用继续遵守现有控制权与静止条件；
- 800×560 和宽屏的记录、分析、参数与停止操作。

真机验收单独记录七轴关节点动、末端平移/绕偏移 TCP 旋转、停止和收纳；先测重复基线，再测单项候选，比较同条件下的改善与代价。

依据与数值方法详见[自动校准方法评估](research/automatic-calibration-2026-11-22.md)及[录制分析方法研究](research/recording-analysis-methods-2026-11-22.md)。

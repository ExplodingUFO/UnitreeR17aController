# 机械臂自动稳定性校准方案

日期：2026-11-22。本文保留早期方法设计，操作以[实现与试用测试](low-speed-calibration-test-plan.md)为准。当前控制页可直接启动七轴小范围测试，无需设置参数或静止观察；报告含七轴时间曲线与位置/速度对比。末端 IMU 共振辨识、输入整形、完整录制诊断和跨姿态配置尚未实现。控制页录制与日志历史已在 `d8b1308` 提交。

目标是提供类似打印机共振校准的引导流程：使用者设置测试中心、运动范围和工具条件后，点击开始，由程序执行测试轨迹、采集响应、生成补偿并自动复测，最后保存通过验证的配置。先前的录制分析成为其中的测量和计算部分；手动录制仍可用于诊断。

建议做两项互补的校准：关节低速摩擦/前馈校准，以及末端共振与输入整形校准。前者可先利用已有编码器反馈，后者建议增加带本地采样时间戳的末端三轴加速度计。当前同向慢移中的停滞后追赶优先进入前者，不能预先认定它属于结构共振。

## 1. 自动校准流程

控制页“参数”中增加“稳定性校准”入口，打开二级弹窗。向导分为“范围、测试、结果”，原有记录分析的“概览、曲线、优化”在结果中查看。800×560 内容区内只显示当前步骤，导航、进度与停止按钮固定。

1. **设置范围**：示教当前测试中心，选择关节或末端方向、运动范围、速度/加速度/jerk 与逐轴参数试验上限，记录 TCP、安装方向及工具/负载条件。3D 预览完整测试路径。
2. **测量基线**：自动执行静止、受限正反向恒速、起停和短往返，记录七轴目标、发送与反馈；共振校准同时记录末端加速度。
3. **分析响应**：检查有效数据与驱动状态，区分发送、摩擦跟随和振动问题；按速度、方向、姿态与参数版本分段。
4. **计算候选**：拟合可辨识的摩擦参数，或在预设试验范围内生成小规模候选；共振部分拟合局部模态并比较整形器。预测值与实测值分别保存。
5. **自动复测**：程序在片段之间静止时切换候选，重复相同测试路径，比较基线与候选。数据不足时自动补测已设范围内缺少的片段；需要扩大范围时结束本轮并列出要求。
6. **保存结果**：显示改善幅度、响应延时、停止和路径影响。使用者点击“使用结果”后保存当前已验证配置，并可恢复上一组。

一次启动覆盖预览中的测试计划，不要求逐个点动或逐个手动拧参数。只读“分析录制”入口继续不申请控制权；自动校准是独立的主动运动操作，沿用运动命令的控制权、上下文和停止规则。

正常完成后回到测试中心，恢复起始参数并保持当前使能状态；点击“使用结果”再应用和保存推荐配置。取消停止剩余测试，达到静止且仍持有同一控制权时恢复起始参数。故障沿用现有处理，不自动清错或重新使能。

## 2. 一段记录能回答什么

| 检查对象 | 自动计算 | 输出及后续操作 |
| --- | --- | --- |
| 数据完整性 | 每轴有效覆盖、长缺口、丢弃与写入错误、使能/模式变化 | 标出可分析片段与缺失字段；不足时列出补录条件 |
| 参考轨迹 | 速度、加速度、jerk、起停和方向变化 | 定位参考本身的突变；与实际发送、反馈分开显示 |
| 实际发送 | TX 间隔、主机写入耗时、源参考年龄、位置积分一致性、编码差 | 定位发送不连续、量化与时序异常；重复 seq 不直接算重复目标 |
| 关节跟随 | 位置误差、速度起伏、停滞后追赶、方向相关偏差 | 排列受影响关节和片段；结合参考与发送判定异常出现在哪一层 |
| 回传速度 | 设备 dq 与位置趋势估计速度的差异 | 区分速度字段异常与位置轨迹也有波动的情况 |
| 周期波动 | 有效片段的频谱峰、频带能量、多个窗口的一致性 | 给出可分辨频带及证据；时序不足时不生成陷波参数 |
| 驱动状态 | 最早记录到的 error、timeout、模式退出及电压变化 | 显示其与软件 Disabled 报文的先后顺序，不把未记录的首个故障补成结论 |
| 参数使用 | 配置版本、Kd、速度前馈权重、摩擦项与限幅占比 | 分开评价每组参数，避免将多个版本混成一个平均值 |

诊断分成“已检测现象”和“解释假设”。例如，可以确定“恒速目标期间，J2 位置趋势反复接近停滞后追赶”；“摩擦与伺服响应相互作用”需要正反向与参数对照支持。程序显示依据、成立条件和下一项测试，不输出无依据的百分比置信度。

单段记录先做定位，不要求它同时完成摩擦、惯量、重力和 PD 增益辨识。没有有效稳态段时，报告起停行为，不生成恒速标定结果。

## 3. 时间与数据处理

### 三类时间序列保持独立

`control` 是控制周期中的参考与缓存反馈，`transmit` 是发送时对齐后的目标，`feedback` 是逐包回传。分析以新到达的逐轴反馈为观测，不把多次 control 中复用的同一个反馈计成多个独立样本。

- 保留文件顺序与原始时间；分析副本按来源和关节整理。相同时间的样本保留顺序，倒序、重复和缺口单独计数。
- 用 generation、运动类型、axis、方向、stopping、enabled、模式和参数版本划分片段。不同参数、起步、恒速、减速、保持与反向分别计算。
- `seq` 仅关联源控制周期；同一 seq 可以对应不同发送目标。编码差使用对应批次的理想值和 wire 值。
- 每条 RX 对最近已完成的 TX 批次作主机时间匹配，保留批次时间跨度和参考年龄。它是近似配对，不是电机实际采样时刻的恢复。

当前 TX 时间是七轴批次开始时间，`write_us` 是主机写调用耗时；RX 时间在读取后逐包赋值。文件没有设备采样时钟、逐轴上总线时刻或驱动执行确认。因此精确相位、机械延迟与闭环频响不能仅由当前主机时间戳确定。

### 求导、重采样与频谱

先识别同轴接收成簇、微秒级到达和长缺口。位置趋势采用实际时间上的局部多项式拟合；接收成簇时可取每簇最后一包形成低带宽趋势，并保留原始包。禁止直接用微秒级接收间隔差分为机械速度。

报告同时提供原始 dq 和固定窗口的位置速度估计；用多种预先规定的窗口检查结论是否一致，所有记录使用同一分析配置。滤波只用于离线测量，不进入控制或改变导出原始值。长缺口不插值，缺口两侧分别分析；跨轴数据只在共同有效区间比较。

只有覆盖和时序满足条件的片段才重采样。降采样前低通，明确采样率、通带、窗口、去趋势方式、有效时长和缺口处理。频谱使用加窗分段平均；频率间隔约为 `1/T窗口`，零填充不增加实际分辨能力。短片段或接收缓冲主导的片段只给趋势统计，不据此推荐陷波器。

### 指标定义固定

- 位置误差保留有符号偏差、RMS、绝对误差 p95；同时说明目标取自哪一层以及配对方式。
- 稳态速度起伏使用去除局部趋势后的绝对 RMS，并保留绝对单位。接近零速时不使用除以平均速度的百分比。
- 跟随误差与未缩放的运动目标 `dq_ref` 比较；编码误差与 `dq_feedforward` 比较。降低速度前馈权重不能通过降低评价目标获得更好分数。
- 每个指标记录有效时长、样本数、剔除原因和时间加权方式；原始值与延迟估计后的辅助值分开显示。恒速段无法区分固定时间延迟与固定位置偏差时，延迟输出为空。
- 关节指标覆盖七轴。TCP 指标需要模型、TCP 变换与共同时间上的关节估计；缺少这些条件的旧文件仅做关节分析。

## 4. 优化建议如何生成

按异常出现的位置选择操作，不对所有情况统一加滤波或提高 Kd。

| 证据组合 | 优先建议 | 验证方式 |
| --- | --- | --- |
| 参考已有速度/加速度不连续，发送跟随变化 | 检查参考生成、切换与现有 jerk 限制 | 对比相同操作的参考连续性、路径和停止时间 |
| 参考平滑，发送位置变化不连续 | 检查发送时序、对齐与编码量化 | 检查实际 TX 的增量、间隔及跟随变化 |
| 设备 dq 起伏，位置趋势基本平滑 | 检查速度估计、接收成簇与量化 | 比较位置趋势与 dq，先保留现有控制参数 |
| 目标平滑，位置也反复停滞/追赶，方向相关 | 优先标定已有平滑摩擦补偿 | 同姿态、同路径下正反向、多档速度对照 |
| 在可靠时序和多段数据中出现重复频带，参考没有该波动 | 识别伺服/结构响应；安排 Kd 与前馈对照 | 同时检查相邻轴、静止、跟随误差和停止效果 |
| 错误、模式退出、限幅或电压异常与波动重合 | 先处理驱动状态与输出受限问题 | 查清首个记录到的异常，再进行参数对照 |

报告中的建议包含操作对象、理由、适用条件、下一次采集要求和评价指标。已有证据只支持补录时，就输出补录计划，不填写假参数。

## 5. 参数候选与标定

### 先适配已有摩擦模型

保持当前模型 `τfriction = Fc × tanh(v/ε) + B × v`。首轮固定 ε、Kd 与速度前馈权重，估计逐轴 Fc 与 B；不同时搜索全部参数。模型辨识中的 v 取可用的实测速度趋势，部署前再用当前实现的参考速度输入检查同一模型，低速过渡处要单独验证。

在同姿态附近采集正反向、多个可分辨速度的恒速段，去除起停与明显耦合段。若有可校核的关节侧力矩估计和重力/惯性预测，构造力矩残差，并用 `b + Fc × tanh(v/ε) + B × v` 拟合；b 用来暴露该局部姿态中的偏置，不能直接作为额外保持力矩应用。

使用小规模约束最小二乘、鲁棒权重和分列尺度归一化；以 SVD 检查秩和条件数。Fc/B 受现有输入范围及使用者确认的逐轴试验范围共同约束。按完整时间段或整次录制留出验证，不随机拆分相邻点。输出拟合残差、留出误差、参数相关性、适用速度与姿态范围。约束边界是否激活单独显示；处于边界的拟合结果需要结合留出误差判断。

单一窄速度段、零速附近 `tanh(v/ε)≈v/ε`、未知负载或力矩来源不明确时，Fc/B 可能无法分别确定。`tau_ff` 是程序施加值，不能用它回归并证明自身补偿有效；驱动 tau 也不是独立外部力矩传感器。条件不足时仍可分析位置波动，并给出小范围参数对照方案，不生成已标定系数。

### Kd 与速度前馈采用实际对照

B 与 Kd×速度前馈权重在当前参考速度通道中可能合并成等效系数，不同时辨识两者。做速度前馈对照时固定已经选择的摩擦参数，结果不解释为重新辨识了物理摩擦。

当前接口是 PD＋前馈，没有 Ki；现有调试仅暴露 Kd、速度前馈与摩擦参数。Kp 保持现有实现。软件输入范围不作为机械臂的已验证试验范围。

Kd 与速度前馈候选要通过同条件的实际运动评价。第一轮先固定 Kd，自动做摩擦与速度前馈对照；已有失去保持力事件查清后，才在单独确认的逐轴试验范围内做 Kd 候选对照。程序每次只改变一个参数，片段之间静止后应用、记录版本、复测，并保留起始参数。输入范围 0..30 不作为自动搜索范围。

自动试验先用小规模有界候选和单轴坐标搜索：在满足跟随、驱动状态、停止与路径条件的候选中比较速度起伏，改善不明显时结束，不以达到参数边界为目标。先验证单轴关节运动，再验证末端运动所涉及的七轴响应。摩擦候选还要在关闭补偿与启用补偿之间比较；保持、正反向、不同速度和停止均要覆盖。TCP 旋转中心、路径、停止和收纳逻辑保持现状。

## 6. 自动比较怎样判定改善

比较前核对左右臂、模型/标定版本、TCP、安装方向、负载说明、初始姿态、运动空间、坐标系、方向、速度与片段类型。不同条件可以并排查看，不能直接显示“改善百分比”。

在共同的速度与姿态范围内，分别报告基线和候选的：

- 速度起伏 RMS 与位置误差 p95；
- 反向偏差、超调和停止后稳定时间；
- 七轴相邻响应、TCP 路径偏差（条件齐全时）；
- 输出限幅、故障/模式退出、供电与温度变化。

先检查故障、输出受限、跟随和停止是否恶化，再比较主要波动指标。不把各项揉成一个不透明总分；“改善/接近/变差”的阈值来自重复基线测量的波动范围和使用者的验收目标，不预设硬件精度。候选只有在重复对照和留出条件下仍表现较好时才标为推荐；单次比较显示本次结果。

离线重放可以验证算法、编码、限幅、缺失数据处理和候选计算是否一致，不能证明修改参数后的真实闭环响应。

## 7. 现有数据与必要补充

现有记录已足够实现关节诊断：三类来源、逐轴位置/速度/力矩估计、TX 理想值与编码值、P/D、模式与故障、参数版本及前馈分解。现有 `analyze_trace` 输出间隔、参考峰值、control 缓存反馈 RMS 和编码差，可以保留为基础摘要。

为使后续 TCP 分析和前后对照可复现，新录制需要补充：

- 文件格式版本、应用/算法版本、模型与标定内容摘要；
- 实际使用的基座重力方向、Link7→TCP、运动空间/坐标系/请求速度；
- 参数及运动上下文变更的时间和版本；
- 使用者填写的安装与负载说明，以及基线/候选关联。

上述信息在开始录制或上下文变化时记录，不在每个控制周期序列化字符串或读取磁盘。上下文缺失时对应分析项标为缺少条件；不从旧文件猜测 TCP 或负载。日志事件只能按墙钟与采样开始时间作辅助关联，故障分析以录制内 TX/RX 单调时间顺序为主。

## 8. 共振校准与输入整形

### 观测与测试

先在一个常用姿态和当前工具下做局部校准。关节编码器能观察关节跟随，末端柔性振动需要附加测量。建议将三轴加速度计刚性固定在实际工具附近，传感器或采集 MCU 本地定时采样，带序号、采样率与设备时间戳批量上传。主机估计时钟偏移与漂移，并记录同步不确定性。

加速度计同时包含刚体加速度、旋转产生的加速度及重力投影。记录安装变换和位置，结合编码器运动学处理这些分量；必要时使用含陀螺仪的 IMU。测试小范围姿态下的局部模态，不能将全部加速度直接当成振动。

先确定本轮摩擦/前馈和 PD 配置，再测该配置下的整体闭环响应。之后更改 PD 参数时重新核对模态，不沿用旧响应预测整形效果。

先测静止噪声，再做小幅、短时、分频段的正弦/平滑扫频或多正弦，测量对应姿态下的残余响应与轴间耦合。幅值随频率调整，同时满足角度、速度、加速度与 jerk 约束，不能照抄打印机测试幅度。恒频正弦的幅值可先按 `min(位置范围, v_max/ω, a_max/ω², j_max/ω³)` 筛选；加入起停包络或扫频后需重新检查全部导数。有效幅度还要超过编码量化与传感器噪声，不能激励的频段标为不可辨识。

当前主机每 10 ms 发送一批命令，离散命令的理论 Nyquist 上限为 50 Hz；实际可用频带更低，须通过发送节拍、执行响应与有效激励确定。IMU 高采样率可以改善观测，但不会提高这条命令链的控制带宽。标定报告记录可观察与可补偿频带。

### 整形器与轨迹路径

整形器中的模态阻尼比来自响应拟合，与驱动 Kd 分别记录。从正系数 ZVD 开始，按实测频率与阻尼的不确定区间比较残余响应；确有需要时再加入 EI 等较宽频带候选。候选权重归一化，报告总尾部长度与平均延时，并同时评价运动时间、路径误差、停止距离和振动残留。

推荐对有限动作的公共路径进度 `s(t)` 作整形，然后由原来的路径/运动学产生七轴参考：

```text
路径和速度计划 → 公共进度整形 → TCP/关节目标
                         ↓
运动学与导数约束 → 发送时间对齐 → PD、重力与摩擦前馈 → 串口
```

直线和绕 TCP 的旋转共用同一进度，旋转仍使用原有 TCP 变换与四元数路径。独立滤波各轴最终位置可能破坏几何关系；即使使用公共进度，也要重新检查非线性运动学后的速度/加速度/jerk 和 TCP 路径。约束修改了整形输出时，候选的理论预测作废，必须按实际发送重新评价。

公共进度整形是保持路径的局部适配方案，不保证对七轴的所有耦合模态同时有效。初版先验证一个局部工作区域和有限往返动作，再将已通过的整形接到连续点动。连续输入松开、过期、显式停止与故障均优先现有停止处理：丢弃剩余整形尾部，从已发送参考状态进入受限减速，不继续执行排队测试。

### 配置的适用范围

保存机械臂/模型/标定版本、TCP、工具/负载、安装、姿态区域、速度范围、实测模态、整形系数和验证指标。参数绑定实际测试过的范围。跨区域的路径先选全程适用的已验证配置；没有覆盖时使用基线，不在运动中切换滤波器。工具或负载变化后重新测量对应配置。

## 9. 代码组织与运行方式

保留现有控制、发送时间对齐与日志结构。新增代码按两个集中责任组织：

- `analysis.rs`：校验、分段、时序处理、诊断、拟合、候选与比较；不接收串口、控制句柄或数据库句柄。桌面和 CLI 调用同一个计算入口。
- `calibration.rs`：一次校准计划的状态、片段顺序、参数试验和复测判定；调用现有受限运动与参数应用逻辑，不另写串口驱动或浏览器定时控制循环。

输入整形的固定容量延时缓冲与轨迹取样放在现有 `trajectory.rs`，`arm.rs` 接入校准动作及停止优先级。分析拟合在后台执行，实时路径只读取不可变系数并计算少量延时项，不在控制周期进行拟合、SQL 或 JSON 编码。

当前 CLI 保留原有摘要字段与含义，新指标另命名。解析与旧格式兼容集中处理。现有 example 不在图索引范围内，本设计已直接核对其源码。

每个校准批次只运行一项任务。测试动作在 Rust 控制状态中推进；前端只负责启动、显示、停止与保存，不用定时 HTTP 请求逐点驱动。参数只在片段之间静止时应用，等待实际确认后才运行下一段。全部试验沿用单一控制权；关闭、失去控制权与停止会取消剩余计划。

每个测试片段沿用有界短时录制，按校准批次归档原始数据、起始配置、候选与最终验证；这类选定数据不参与普通“最近 10 次”录制的自动清理。批次限定片段数与总样本量，校准记录支持显式删除。加速度计使用有界批数据通道，不逐点通过 UI 状态流传输。后台写盘和控制采样仍分开，不在生产者路径等待磁盘。

分析报告保存输入摘要、算法/选项版本、有效片段和适量曲线点。拟增加的只读分析接口仍为：

| 请求 | 输入 | 输出 |
| --- | --- | --- |
| `POST /v1/traces/{id}/analysis` | `{baseline_trace_id?:string}` | `202 {analysis_id,status}` |
| `GET /v1/analyses/{analysis_id}` | 无 | 状态、进度及报告 |

主动校准通过运动命令通道接入，要求现有 owner、lease 与 generation；不让只读分析接口触发运动。首版 `calibrate_start`、`calibrate_apply` 与状态字段见[API 接入说明](implementation-contract.md#510-低速稳定性校准)，机器可读定义见[OpenAPI](openapi.json)。

报告结构仍集中为 `quality / segments / metrics / findings / candidates / comparison / provenance`。校准批次增加测试范围、片段计划、当前步骤和已应用试验配置。保存结果复用现有 `configure_servo` 的确认与静止规则；整形配置同样在静止时切换。

## 10. 实现顺序与验收

第一步交付基础自动校准：使用者示教范围后，程序自动执行正反向、多档速度与起停轨迹，完成数据检查、摩擦/前馈候选和自动对照验证。先在当前常用姿态、当前工具下验收；Kd 保持基线。第二步接末端加速度测量，在相同向导中增加局部共振辨识与输入整形，并在姿态和工具条件内验证。持续在线改变增益不属于这套一次校准流程。

离线验收覆盖：

- 理想平滑、参考突变、发送阶梯、速度量化与位置量化；
- RX 成簇、重复时间、乱序、缺帧、长缺口和七轴异步；
- 速度字段异常而位置平滑，以及位置本身有停滞/追赶；
- 配置切换、起停与反向分段、故障发生与 Disabled 的先后；
- 已知参数的合成摩擦数据、不可辨识数据、限幅与时间块留出；
- 降低速度前馈不降低评价目标、候选比较条件不一致时不误报改善；
- 旧格式、来源清理、重启后报告恢复、后台取消和并发负载；
- 从分析到填入草稿不下发动作，应用继续遵守现有控制权与静止条件；
- 整形系数、分数延时与端点收敛；TCP 平移/旋转路径、停止和输入过期时清除尾部；
- 校准片段顺序、候选只在静止切换、失去控制权/关闭时取消剩余测试；
- IMU 时间映射、丢包与坐标/重力处理，以及加速度采样负载；
- 800×560 和宽屏的记录、校准步骤、结果、参数与停止操作。

真机验收单独记录七轴关节点动、末端平移/绕偏移 TCP 旋转、停止和收纳；先测重复基线，再测单项候选，比较同条件下的改善与代价。

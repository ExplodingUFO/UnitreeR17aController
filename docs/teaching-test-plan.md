# 拖动示教：操作与测试

2026-11-23。示教在控制页的“示教”弹窗完成：录制手动拖动的七轴位置，保存到 SQLite，预览接近与回放路径，再按所选倍速执行。接口字段见[API 说明](implementation-contract.md#511-拖动示教)与 [OpenAPI](openapi.json)。

## 操作

1. 取得控制权，连接对应侧机械臂并确认使能和反馈，使用当前 TCP；自定义工具仍通过 `configure_tcp` 设置。控制页打开“示教”，在“录制”页输入名称并点击“开始录制”，等待状态确认。
2. 按住拖动按钮或空格，进入拖动后移动机械臂；松开时保持当前位置，可反复拖动和保持。空格仅在弹窗操作区域生效，编辑输入框时不触发拖动。切换时间默认 0.4 s，可在展开设置中调整为有限正数。
3. 点击“结束并保存”，等待恢复保持和 `teaching_saved` 结果。关闭弹窗、Esc 或停止均先结束当前拖动/动作；失焦、页面隐藏、指针取消也会释放拖动输入。输入链路失效时桌面调用现有停止入口，后端同时独立检查输入有效期。
4. 在“轨迹”页选取历史记录。3D 用不同路线区分“接近起点”和“录制路径”，同时显示真实模型、TCP 与连杆扫掠；按阶段播放或拖动进度，检查从当前姿态到首点的整段接近。
5. 设置回放倍速与轨迹平滑，等待新预览后点击“回放轨迹”。回放先接近首点，再执行完整路径，正常完成保持末点。“停止”取消余下动作；收纳、到位断开与退出继续使用已有收纳流程。

`speed_scale` 默认 1，接受有限正数；`smoothing_s` 默认 0.12 s，接受有限非负数，0 也有效。规划依据当前运动设置与模型速度约束重定时，不增加独立的倍速、幅度或时长上限；以预览的实际倍速和总时长为准，总时长包含接近段。

正常拖动/保持切换持续使用伺服模式、模型重力补偿和当前阻尼。进入拖动时平滑降低位置刚度，释放时以当时实测位置建立保持目标并恢复刚度；反复切换从正在执行的过渡继续，不跳回开始姿态。

## 数据与曲线

录制点为 `{t_ms,q:[七轴弧度]}`，时间来自录制开始后的单调主机时钟，包含拖动与保持期间的实测位置。样本按小块追加，控制周期不全量复制、不排序或重采样，不因达到固定点数或时长而截断。

结束后的完整轨迹先保留在内存，历史、详情、下载及回放准备在 SQLite 提交前即可使用；连续保存多条也保留各自的数据。控制线程只尝试提交共享录制对象，队列受阻则保留补投；JSON 编码、轨迹展开与摘要/点数据的同事务写入由后台写入线程完成。旧录制的分块数据在控制快照释放引用后由后台回收。持久化后可在重启后读取；用户示教轨迹不随校准报告保留清理。`teaching_saved` 表示完整录制已形成，不是磁盘事务完成通知。

曲线区分“录制”“规划指令”“回放实测”。录制是原始实测位置；规划指令包含平滑、重定时和接近；回放实测来自本次状态快照，仅代表收到的反馈样本。回放重新生成 `q/dq/ddq` 参考，经现有发送取样与伺服补偿流程执行，不把原始扭矩作为回放命令。需要比较实际报文目标时使用既有短时采样的 `control/transmit/feedback` 数据，不能将 3D 预览或低频状态曲线视作串口发送记录。

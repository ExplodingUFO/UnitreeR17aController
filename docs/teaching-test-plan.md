# 拖动示教：操作与测试

2026-11-23。控制页“示教”弹窗提供持续拖动模式、独立位置录制和轨迹重放。录制既可用于手动示教，也可记录点动、校准、收纳返回或重放期间的七轴实测位置。接口字段见[API 说明](implementation-contract.md#511-拖动示教)与 [OpenAPI](openapi.json)。

## 操作

1. 取得控制权，连接对应侧机械臂，打开控制页“示教”。顶部始终显示“位置保持 / 拖动示教”。手动示教时先使能并点击“拖动示教”，等待进入拖动后用手移动机械臂，无需一直按着按钮。切换时间默认 0.4 s，可在展开设置中调整为有限正数。
2. 输入名称，点击“开始录制”。这一步只记录七轴实测位置，不改变当前运动、模式、使能或 generation。点击“位置保持”可固定当前姿态，录制继续；也可在保持、点动、步长、校准、收纳返回和重放过程中录制。已连接未使能时，有有效反馈也能录制。
3. 点击两个页签均可访问的“结束并保存”。若处于拖动模式，会平滑恢复当前位置保持后保存；其他情况下只结束录制，原软件动作继续。等待 `teaching_saved`，随后选择保存的轨迹。切换页签、失焦或页面隐藏不打断录制和模式。“收起”返回控制页并继续记录，入口显示录制状态，可再次打开；使用位置保持后收起，可连续记录控制页的多次点动。停止按钮和 Esc 停止机械臂，录制继续。关闭按钮或实际卸载示教弹窗会显式结束并保存录制，同时按需结束拖动或本次重放。
4. 在“轨迹”页选取历史记录。3D 用不同路线区分“接近起点”和“录制路径”，同时显示真实模型、TCP 与连杆扫掠；按阶段播放或拖动进度，检查从当前姿态到首点的整段接近。
5. 设置回放倍速与轨迹平滑，等待新预览后点击“回放轨迹”。回放先接近首点，再执行完整路径，正常完成保持末点。“停止”取消余下动作；收纳、到位断开与退出继续使用已有收纳流程。

`speed_scale` 默认 1，接受有限正数；`smoothing_s` 默认 0.12 s，接受有限非负数，0 也有效。规划依据当前运动设置与模型速度约束重定时，不增加独立的倍速、幅度或时长上限；以预览的实际倍速和总时长为准，总时长包含接近段。

正常拖动/保持切换持续使用伺服模式、模型重力补偿和当前阻尼。进入拖动时平滑降低位置刚度，切回保持时以当时实测位置建立目标并恢复刚度；反复切换从正在执行的过渡继续，不跳回开始姿态。持续模式无需拖动输入续期，控制权继续按原有租约续期；停止、失去控制或退出恢复保持。

界面分别读取三个状态：`teaching_mode` 为拖动模式，`teaching_recording` 为独立录制，`teaching` 只为重放。录制可以与拖动或重放同时存在；点击开始录制不创建新的运动动作。

## 数据与曲线

录制点为 `{t_ms,q:[七轴弧度]}`，时间来自录制开始后的单调主机时钟，包含所录期间的有效实测位置，不依赖是否正在使能或手动拖动。样本按小块追加，控制周期不全量复制、不排序或重采样，不因达到固定点数或时长而截断。普通停止、点动输入到期、动作完成、故障和使能/失能不结束独立录制；有有效反馈就继续采集，缺失时不编造点。显式结束、失去或释放控制权、断开、关闭示教弹窗和应用退出会结束并保存已有数据；结束保存不要求当前反馈仍然有效。

结束后的完整轨迹先保留在内存，历史、详情、下载及回放准备在 SQLite 提交前即可使用；连续保存多条也保留各自的数据。控制线程只尝试提交共享录制对象，队列受阻则保留补投；JSON 编码、轨迹展开与摘要/点数据的同事务写入由后台写入线程完成。旧录制的分块数据在控制快照释放引用后由后台回收。持久化后可在重启后读取；用户示教轨迹不随校准报告保留清理。`teaching_saved` 表示完整录制已形成，不是磁盘事务完成通知。

曲线区分“录制”“规划指令”“回放实测”。录制是原始实测位置；规划指令包含平滑、重定时和接近；回放实测来自本次状态快照，仅代表收到的反馈样本。回放重新生成 `q/dq/ddq` 参考，经现有发送取样与伺服补偿流程执行，不把原始扭矩作为回放命令。需要比较实际报文目标时使用既有短时采样的 `control/transmit/feedback` 数据，不能将 3D 预览或低频状态曲线视作串口发送记录。

## 离线验收

以下为验收要求，运行结果、命令和证据统一记录在[测试记录](implementation-status.md)。离线使用合成反馈、内存/临时 SQLite、测试路由和界面模拟，不连接设备或占用应用的 8177 端口。

| 拖动与保持    | 单击持续进入拖动；切回保持时固定当时位置并恢复刚度；过渡中反向切换连续，重复开启不重启过渡。模式独立于录制，无需按住/空格或拖动输入续发。检查输出仍为 Servo，重力与阻尼持续存在。                                  |

## 实现说明

控制线程独占设备、目标、租约与动作；通信逐关节有界事务，连续输入采用最新消息槽，桌面停止/退出单独用原子信号。使能等待七轴设备反馈；设备 watchdog 触发后故障锁定，正常反馈不会复活旧动作。

关节参考先约束最终发送速度，再按实际周期积分，避免绝对时间插值在周期抖动时突破加速度。步进到达时还需实测与参考均在容差内，继续受限减速到零后才报告 completed。

SQLite 使用专用 writer、WAL、批量事务。控制线程只做有界 `try_send` 和原子统计，不等磁盘或数据库锁；日志查询放到 `spawn_blocking`。队列满计 dropped，数据库失败计 errors，后台重试。退出时由协调线程限时等待刷新。控制周期受操作系统调度和串口驱动影响。

后端由六个 Rust 模块组成；前端按工作台、布局、三维、API 与样式组织。代码已统一格式化并提供检查命令。面板调整使用原生 Pointer Events，没有新增运行依赖。服务随桌面应用启动和关闭。

生产前端包含 Three.js，单个压缩前 JS 包约 909 kB；Vite 提示超过默认 500 kB 的建议阈值，构建成功。当前为本机开发包，未进行分发签名或公证。

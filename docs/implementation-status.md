## 2026-11-22 模型行程与路径预览

- 采样复现：本轮记录有 1,388 点，在 35.749 秒因发送参考相对控制参考的横向差达到 0.050129 mm，被旧 0.05 mm 检查结束。移除发送端重复的 FK、路径和固定增量拒绝；来源暂时过旧时保持最近成功目标，新参考到达后继续。同一记录离线回放通过。记录未执行到参数候选，不能作为补偿前后结果。
- 行程：根据 URDF、当前姿态和 TCP 分别延续各方向的可达关节构型。默认自动行程，也支持指定正幅度与速度，移除 100 mm、15 mm/s 和 10% 余量。该采样起姿的局部可达偏移为 X −355.6～+306.4、Y −343.7～+85.6、Z −98.6～+245.2 mm；不是所有构型的全局工作空间。
- 执行：预览附带最多 51 个按关节曲率挑选的构型参考点，随程序原样提交。位置边界包含启动时实际接受的保持位置；整组 TCP 路径仍使用预览的原点与方向。速度、加速度和 jerk 可编辑，默认 1 / 0.6 / 6，模型各轴速度单独读取。
- 画面：默认显示单轴路线、方向、距离、关键姿态与肘腕扫掠，提供立体、俯视、正视、侧视及播放。范围盒默认关闭，空方向自动选择可见阶段。[800×560](screenshots/calibration-model-paths-800x560.png)、[宽屏](screenshots/calibration-model-paths-1440x900.png)、[三向总览](screenshots/calibration-model-overview-800x560.png)、[关节扫掠](screenshots/calibration-model-joint-sweep-800x560.png)均使用 Rust 生成的 3,788 点几何，连接和设备状态使用测试响应。

## 2026-11-22 校准启动与准备界面修复

- 现象：机械臂已停稳、保持使能，点击开始后仍提示 motion_busy。可在固定位置、回传 dq=0.03068 rad/s 的命令入口测试中稳定复现。旧代码用七轴最新 dq 任一超过 0.02 rad/s 判断运动，静止段速度尖峰会误拒绝；还会影响校准内部往返的到位确认。
- 修复：使用七轴新收到的位置历史确认静止，覆盖 300 ms，窗内最大跨度不超过 0.001 rad；逐轴检查有效覆盖、100 ms 新鲜度与缺口，非有限、重复或倒退时间重建观测。原始反馈不滤波、不改值；控制权、发送目标、跟随和上下文检查继续执行。仅校准内部 Return 改用位置判稳，普通收纳到位断开保留原有速度检查。
- 回放：私有采样的静止窗口在 478198 us 出现旧速度门槛误拒绝条件，当时有效位置跨度约 0.0000958 rad。新命令入口接受启动；原文件仍在忽略目录，回放默认测试忽略并通过环境变量指定路径。
- 界面：设置页显示开始前检查、确认进度、具体关节与位置波动；准备完成后才能开始，不自动重试。可恢复拒绝转为最新准备状态，原因解除后不继续挂旧的 motion_busy；故障、网络异常和其他拒绝仍显示。所有操作仍在当前弹窗完成。
- 审查：独立源码复查确认时间窗口、每包异常、内部到位、控制权及停止/收纳路径，没有发现必须修复的 P1/P2。

## 2026-11-22 低速自动校准首版

- 入口：控制页“参数 → 低速校准”。在同一弹窗设置关节、相对位移、速度与补偿试验上限，查看进度、结果和历史；关闭重开继续显示当前任务，Esc 请求停止。检查了 [800×560 设置](screenshots/calibration-settings-800x560.png)、[结果](screenshots/calibration-result-800x560.png)及 1440×900，截图使用模拟状态，改善比例为示例。
- 方法：单轴有限往返，两档速度；固定 Kp/Kd，分别试验库仑摩擦与速度前馈候选。通过 100 ms 位置窗口比较未缩放运动参考与反馈，候选需经过重复基线与复测；无改善或数据不足不推荐。完成先恢复起始配置，再由使用者显式应用。首版保存逐轮统计和配置，完整逐帧数据沿用已有录制；未实现 IMU 共振识别或输入整形。
- 运动：复用受限收纳轨迹，补充五次曲线的 jerk 时长下限，避免小幅快速片段落后并越界。保持原有 TCP、点动、停止与收纳处理；停止、控制权过期、失能、断开及故障取消剩余测试，故障不自动重新使能。
- 持久化：现有 SQLite 保存最近 100 份报告，读查询在 spawn_blocking；后台序列化和事务不进入控制周期。单次 try_lock 未接纳时保留报告，后续补投；退出时在控制结束后交接补投，再刷新数据库。历史报告只读，不获得新连接的应用资格。
- 独立审查：两位审查者检查控制、参数恢复、前端确认与持久化。修复 TX/RX 因果配对、TCP A→B→A 恢复旧资格、报告队列竞争丢失、HTTP 明确拒绝后无限等待四项问题，并完成限定复查。

## 2026-11-21 平滑摩擦与逐轴伺服调试

- 配置：新增完整 `ServoTuning`，全局摩擦开关及七轴阻尼、速度前馈权重、库仑/黏性系数、平滑过零尺度与摩擦上限。基线摩擦关闭，每轴 `10/1/0/0/0.02/0.5`，范围与单位见[接口说明](implementation-contract.md#59-伺服调试配置)。调试页支持草稿、恢复基线、显式应用及复制 JSON。

## 实现说明

控制线程独占设备、目标、租约与动作；通信由独立串口 I/O 线程沿原始 10 ms 网格批量下发七轴，跳过错过槽位，按发送时刻取样最新参考。控制线程只发布最新参考和读取带时间戳反馈，连续输入采用最新消息槽，桌面停止/退出单独用原子信号。使能等待七轴设备反馈；设备 watchdog 触发后故障锁定，正常反馈不会复活旧动作。

关节参考保留原有 Euler 积分，先约束将要积分的速度、加速度与 jerk，再按实际周期积分。末端在 Jacobian 求解中使用同一导数窗口，候选经 FK 检查。步进到达时还需实测与参考均在容差内，继续受限减速到零后才报告 completed；发送端可对同一源多次取样或合并更新，控制参考约束不保证实际 TX 节拍或物理 jerk。

事件 SQLite 使用专用 writer、WAL、批量事务。控制线程构造字段长度有界的记录，单次尝试取得预分配队列锁，竞争或满队列立即计 dropped，不等队列或磁盘；统计只读原子值，日志查询放到 `spawn_blocking`。数据库失败计 errors，后台重试。短时采样使用独立队列与 writer。退出时由协调线程限时等待刷新。控制周期受操作系统调度和串口驱动影响。

Rust 后端按控制、协议、运动学、轨迹、接口、事件日志和短时采样组织；前端按工作台、布局、三维、采样、API 与样式组织。仓库提供格式检查命令。面板调整使用原生 Pointer Events，没有新增运行依赖。服务随桌面应用启动和关闭。

生产前端包含 Three.js，单个压缩前 JS 包约 1.07 MB；Vite 提示超过默认 500 kB 的建议阈值，构建成功。当前为本机开发包，未进行分发签名或公证。

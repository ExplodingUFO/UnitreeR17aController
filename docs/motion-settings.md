# 运动设置与执行条件

2026-11-22。审计范围为 `src-tauri/src` 的 14 个 Rust 文件和 `src` 的 12 个前端文件，分别核对控制流程、运动学与预览、串口与补偿、界面与 API、记录与退出。

## 数值由哪里决定

| 内容 | 来源 |
| --- | --- |
| 关节速度 | 用户的 `MotionTuning.joint_speed` 与 URDF 各轴速度 |
| 加速度、jerk | 用户的 `MotionTuning`，关节、末端、返回共用 |
| 末端速度、步长、校准行程 | 用户输入；自动预览根据当前姿态和模型计算可达路线 |
| 路径上的可执行速度 | 当前路径的关节变化量和同一份运动设置 |
| 阻尼与最终报文字段 | 协议编码的实际可表示范围 |
| 摩擦补偿幅值 | 用户的 `max_friction`；总附加前馈随后按协议编码 |
| 点动输入有效期、录制时长 | 可表示的正时长，沿用默认值但没有另一套固定范围 |

速度、长度、角度均需有限；参数的正负要求与其数学含义一致。毫米、度与 API 的米、弧度之间仍做单位换算。

## 本次移除的独立门槛

| 原行为 | 当前行为 |
| --- | --- |
| 补偿模块把速度限制为 0.2 rad/s，超过即退出发送线程 | 使用运动设置和模型给出的速度，不再在补偿层设另一上限 |
| Kd 30、速度前馈 1、Fc 2、黏性 10、过零尺度 0.001～0.2、摩擦限幅 2 | 移除这些软件范围；保留数学符号及实际编码要求 |
| 重力前馈和总附加前馈另设 8 Nm 上限 | 移除重复的固定上限；摩擦分量仍按用户设置限幅 |
| TCP 平移限制为 ±2 m，较小非零四元数被拒绝 | 接收有限平移，归一化非零有限四元数 |
| 启动前要求发送记录足够新、属于当前上下文且七轴严格零速 | 起点取同一连接最近成功发送的位置，尚无记录时使用当前有限参考 |
| 起点、运行和求解器重复设置 0.6 rad 跟随窗口及步长窗 | 删除独立的跟随拒绝和重复步长窗口；参考导数使用统一运动设置 |
| 七轴都未过期，仍因接收跨度超过 100 ms 被拒绝 | 逐轴使用有效反馈，不增加第二道跨度门槛 |
| 收纳超过预计时长 3 秒即失败，位置抖动反复重置 200 ms 观察 | 等实际位置到位和参考减速完成；没有额外稳定窗口或预计时间误停 |
| 校准阶段等待前一动作停止仅允许 2 秒 | 等当前动作实际停止；显式取消仍取消后续步骤 |
| 参数版本变化后，校准推荐不能再次应用 | 用户可显式应用推荐；以当前配置显示是否已应用 |
| 很低的速度不进入校准指标，较长采样间隔被直接丢弃 | 按动作阶段和实际时间差计算，不用固定速度门槛过滤 |
| 界面把平移步长压在 0.1～10 mm、旋转步长压在 0.1～5° | 接受有限正步长 |
| 收纳速度不超过 0.2 rad/s，单轴目标变化不超过一圈 | 接受有限正速度和七轴有限目标，使用统一运动设置生成返回轨迹 |
| 连续点动有效期限制为 50～500 ms | 接受计时可表示的正整数毫秒 |
| 录制必须是 1～20 整数秒，历史读取失败或上一份还在写入就不能开始 | 接受可表示的正时长；历史查询、后台写入与新录制分开处理 |
| 请求体限制 16 KiB，预览为此压缩到最多 51 个关节参考点 | 使用框架默认 2 MiB 请求资源边界，保留实际规划点 |
| 报文间的主机调度间隙计入统一 20 ms 截止，导致下一完整报文尚未写入就判失败 | 单个报文保留有限 I/O 进度等待；完整报文间的调度间隙不再造成该误判 |
| 优先命令失败后仍可能继续旧缓存，清错报文被当作周期心跳 | 失败终止旧发送；清错按一次操作发送，后续心跳恢复失能状态 |

客户端、请求标识和串口名也去掉了独立的 64/100/300 字节帽。请求仍受总请求体资源边界约束，标识与设备名须非空。

## 仍需满足的执行条件

| 条件 | 含义 |
| --- | --- |
| 单一控制权、当前命令上下文 | 防止多个客户端同时驱动；旧动作在停止或转交后不能复活 |
| 连接、使能和单动作互斥 | 命令需有对应设备状态；设置 TCP、参数和切换动作不能彼此覆盖 |
| 输入真正到期、显式停止、取消 | 取消动作本身，不因放开数值范围而删除停止功能 |
| 七轴完整有效反馈、设备故障与通信状态 | 不把缺失或失联数据当作当前姿态，也不隐藏设备上报的故障 |
| 预览对应的臂侧、TCP 与起始姿态 | 确认执行的路线应对应用户看到的预览 |
| 到位断开的实测位置 | 实际位置尚未到时继续保持连接与使能；不能只看时间进度就释放 |
| 预览的模型几何边界、协议字段及有限数值 | 求解需得到可计算、可编码的结果 |
| 有界队列、分页、记录容量和数值求解收敛 | 控制与 SQLite 写入分开，资源问题不作为新的运动范围上限 |

以上条件的具体输入输出见 [API 说明](implementation-contract.md)。构建、离线回放和界面检查结果见 [测试记录](implementation-status.md)。本轮改动未连接真机验证，不把数值回放当作物理减抖效果。

当前校准先测所选关节的基线，再优先在误差较大的两轴比较摩擦与速度前馈候选。这是候选搜索策略，不是动作拒绝条件；七轴基线和末端前后对照都会保留。单轴模式仍可分别选择其他关节。

# R1-7a 控制器首版规格（1.0）

状态：已实现 macOS arm64 软件 MVP。更新日期：2026-11-09。当前测试、构建、打包与验收证据统一见[实施状态](implementation-status.md)，接口细节见[实施接口](implementation-contract.md)。技术取舍见[架构决策](adr/0001-controller-architecture.md)，历史交互评审见[原型说明](prototype.md)。软件实现完成不等于真机验收。

## 1. 交付目标与边界

首版是一个 Tauri 2 桌面应用：所在电脑经厂商 USB 转接器直连独立 R1-7a，Rust 后端处理设备与运动，同时向其它本机服务提供 HTTP/WebSocket。窗口关闭时后端一同结束。控制权唯一，显式释放或转交。

当前软件 MVP 环境为 macOS arm64。Windows/Linux 的构建、运行及设备验证均未验收。机械臂和转接器当前不可访问，所以真机端到端 MVP 仍未验收。

产品已按冻结接口并行实现；实施进度与最终证据由[实施状态](implementation-status.md)维护，不在本规格中固定测试数量或推定未完成检查已通过。

范围包括连接、状态、使能/停止、七轴关节和末端六维的连续/步长点动、基座/工具坐标、当前七轴局部运动学、实测模型、本机调用与必要诊断。工作台宿主始终可以取消当前动作，不取得控制权，也不自动失能。

首版不包含全局位姿搜索、任意轨迹规划、相机/点云、双臂/灵巧手、录制回放、图表平台、插件、无窗口驻留或局域网预留。

## 2. 技术选型

| 部分 | 确定方案 | 职责 |
|---|---|---|
| 桌面 | Tauri 2，React + TypeScript + Vite | 一个工作台、应用生命周期与本机能力 |
| 三维 | Three.js + URDFLoader | 加载官方 URDF/STL，使用实测关节值更新模型 |
| 通信 | serialport 4.10.1 | 跨平台串口；当前 IM6014 报文/CRC/标定由项目实现 |
| 数值 | nalgebra 0.35.0 + urdf-rs 0.10.0 | 当前七轴 FK、TCP 几何 Jacobian、统一局部加权 DLS 步 |
| 本机接口 | Axum 0.8 系列 + Tokio | HTTP 请求、WebSocket 状态；控制线程独立调度 |
| 数据 | serde/JSON；rusqlite 0.41.1（bundled）+ crossbeam-channel | SQLite 结构化事件日志，后台写入，有界队列隔离控制线程 |

以上为当前产品依赖基线，依赖清单和锁文件随产品保存；依赖解析与构建检查结果见[实施状态](implementation-status.md)。串口与数值版本依据现有研究；采用直接 nalgebra 路线的依据与验证责任见[数值评估](research/nalgebra-direct-assessment.md)。本机接口的实现依据为 [Axum 官方文档](https://docs.rs/axum/latest/axum/)。

Rust 后端位于 Tauri 应用中，本机接口不另起服务进程。前端所有设备动作与其它本机调用方进入同一控制模块；宿主退出和总停止也调用该模块，不另做一套运动逻辑。

桌面的一般操作和状态统一走本机 HTTP/WebSocket。Tauri 宿主只提供会话连接信息和总停止两个薄入口；宿主关闭由应用生命周期处理。网络和宿主入口都调用同一个 arm，不分别维护运动逻辑。

宿主入口只向打包的主窗口开放，不授权远程页面。开发与打包 WebView 的 Origin、CORS、CSP 和资源 URL 按本机访问配置；具体联调证据见实施状态，访问失败作为待修复问题处理。Tauri 的命令、窗口权限与 CSP 配置方式分别见[命令文档](https://v2.tauri.app/develop/calling-rust/)、[能力文档](https://v2.tauri.app/security/capabilities/)、[CSP 文档](https://v2.tauri.app/security/csp/)。

两个宿主自定义命令显式纳入 AppManifest 的命令权限管理，再仅向 main 窗口授予对应能力；不能只注册 invoke_handler 就假定命令已经限制到主窗口。HTTP 入口始终不具有宿主身份。

## 3. 单页工作台静态布局

下面是范围和信息位置示意，不是应用截图。

```text
┌───────────────────────────────────────────────────────────────┐
│ 设备/后端状态       反馈年龄       控制者       [取得控制] [停止]│
├─────────────────┬──────────────────────────┬──────────────────┤
│ 连接与关节       │                          │ 点动             │
│ 左/右臂型号      │        3D 机械臂         │ 末端 / 关节      │
│ 串口与连接       │                          │ 连续 / 步长      │
│ 使能/失能        │ 实测模型 / 参考姿态      │ XYZ 及姿态 ±     │
│ 七关节反馈       │ 关节计算 TCP 与坐标轴     │ 速度与步长       │
│ 状态与故障       │ 参考/实测/过期来源标识    │ 当前动作与原因   │
├─────────────────┴──────────────────────────┴──────────────────┤
│ 诊断：最近错误、反馈丢失/校验计数、控制请求结果、本机接口地址    │
└───────────────────────────────────────────────────────────────┘
```

| 区域 | 首版内容 | 行为约定 |
|---|---|---|
| 顶部状态 | 连接/使能、反馈年龄、当前控制者、取得/释放控制、停止原因 | 状态来自同一后端快照；连接成功不代表可运动 |
| 左侧连接 | 端口枚举、左右臂配置、连接/断开、使能/失能 | 更换设备/TCP/配置时先结束旧动作并使旧请求失效 |
| 关节反馈 | 七关节名称与 q、dq、扭矩估计；可得的温度/电压与故障 | 缺失或过期值显示无效，不填零冒充反馈 |
| 关节点动 | 七轴各自的正/负方向、连续/步长操作 | 与末端点动互斥；坐标系选项仅用于末端点动 |
| 中央 3D | 官方模型、关节计算 TCP/坐标轴、参考/实测来源 | 实测模型由反馈驱动；无设备时只显示明确的参考姿态 |
| 右侧点动 | 末端/关节页签；XYZ/姿态或七关节；基座/工具、连续/步长、速度与步长 | 页签共享一种动作状态；无有效控制权、未使能、反馈过期或故障时说明禁用原因 |
| 底部诊断 | 近期有限条日志、错误、请求结果、通信计数、本机接口信息 | 不暴露控制凭据；不做曲线、回放和监控平台 |

生产工作台在 1280×720 与 1024×768 同时显示连接、七轴、3D、点动与日志，无页面级滚动；具体布局检查结果见实施状态。界面不展示原型标识、验收免责声明或解释段落，只显示当前状态、数据来源、操作和必要错误原因。

左右栏边界、3D/末端坐标区边界及日志上边界均可拖动，尺寸保存在本机，双击恢复对应项默认值。日志默认随窗口高度分配 128–192 px，最小 112 px；工作区至少 400 px，末端坐标区至少 140 px。窗口缩小或日志拉高时，关节表和点动列表允许内部滚动，各模块继续保留在当前页面。3D 画布跟随实际面板尺寸更新。

无设备时仍可查看官方模型的参考姿态，关节 q/dq/tau、反馈年龄及反馈计算 TCP 为 `null`；界面明确标“参考模型/未连接”，不生成伪设备反馈。测试夹具只用于验收，不作为可扩展虚拟设备模式发布。

官方资源当前没有单独定义真实工具中心。工具配置不完整时只标注 Link7 参考坐标系，不能把缺省变换当成已标定 TCP；末端点动要求当前 TCP 定义有效。

配置按动作校验：关节点动要求当前模型、标定、反馈和动态限制有效；末端点动额外要求有效 TCP。缺少 TCP 不单独禁用已经满足上述条件的关节点动，Link7 参考帧也不能自动满足末端动作的 TCP 条件。

## 4. 点动交互与控制状态

### 已确认的点动语义

- 同时包含 XYZ 平移和姿态旋转、基座/工具坐标、按住连续与固定步长。平移保持工具姿态，纯旋转绕当前 TCP。
- 七轴分别提供连续/固定角度关节点动；一次只执行一种关节或末端动作。关节点动直接生成受限关节参考，不经过 IK，仍校验七轴反馈、关节限位和动态约束。
- 连续点动松开、失焦、页面隐藏、输入失效或控制权失效时结束动作；服务端独立校验输入有效期。
- 固定步长每次形成一个平滑局部运动段，运动中拒绝新步长；不积压点击，也不自动重试运动请求。
- 从可信实测状态开始，小步延续已接受构型。首版不独立调肘；局部无法推进或接近约束时降速/停止并解释原因。
- 内部单位为米和弧度。UI 可以显示毫米/角度；姿态内部用四元数/旋转向量，显示 RPY 不决定控制算法。

保持姿态与固定步长以配置的位置/角度容差判定，并用 FK 复核候选结果。局部步同时受关节增量、速度、加减速和参考目标相对实测的偏差限制；无法满足时拒绝候选或停止。这里的平滑指配置内的速度与加减速约束，不宣称精确轨迹跟踪、jerk 连续或全局可达求解。

### 状态语义

| 状态 | 含义 | 可发生的下一步 |
|---|---|---|
| 未连接 | 无打开的设备会话 | 取得控制、连接、参考模型查看 |
| 连接中 | 正在建立会话及收集反馈 | 成功、失败或取消 |
| 已连接未使能 | 端口已打开，设备状态独立报告 | 持有者显式使能；断开 |
| 使能中 | 已发送使能，等待七轴请求之后的新鲜 mode=1、零故障、无超时反馈；一秒期限 | 全部确认后可操作，或停止/确认超时故障 |
| 可操作 | 已使能且基础反馈/配置有效；动作专用条件仍分别检查 | 当前持有者开始满足条件的一种点动，或停止/失能 |
| 运动中 | 唯一一种关节或末端动作，模式为连续或步长 | 续输入、完成、停止、故障 |
| 停止中 | 取消输入并完成控制退出 | 可操作、未使能或故障，不接受新动作 |
| 故障 | 设备/反馈/数值/通信不满足继续条件 | 查看原因，持有者清错/断开；不自动恢复旧动作 |
| 关闭中 | 整个应用正在退出 | 撤销动作和控制权、关闭设备与接口、结束应用 |

控制权与反馈有效性是独立字段，不把它们重复编码成多套状态机。只有控制模块能改变权威状态。

使能必须从当前有效位置建立初始目标，不能沿用上次运行的目标。停止、失能和退出的物理效果按当前设备策略分别处理；当前未取到真机证据，不承诺实际停稳或保持结果。

设备超时状态或运行中退出 mode=1 会锁定故障、取消动作并失能；后续正常反馈不会恢复旧动作。清错须等新鲜、无超时且零故障反馈确认，再由持有者显式使能。

工作台停止可以取消任何客户端的当前动作，保留原控制权归属且不自动失能。取消推进 generation，使旧输入失效，并为原 request_id 产生 cancelled 终态；停止流程未结束时不接收新运动。重新运动仍需持有者显式发起新请求。

## 5. 少量模块与执行线程

产品采用下面的集中模块，不建立额外 workspace 包或多后端框架。模块接口以[实施接口](implementation-contract.md)为准。

| 位置 | 拥有的内容 | 不向调用方暴露的实现 |
|---|---|---|
| src-tauri/src/lib.rs | Tauri 启停、两个宿主薄入口、控制句柄、关闭协调 | 应用和线程资源回收 |
| src-tauri/src/arm.rs | 唯一设备/控制权/动作状态，控制线程、超时与快照 | 串口调度、当前目标、有效期和状态转换 |
| src-tauri/src/protocol.rs | 当前报文、CRC、反馈组帧、单位与标定映射 | 包字段、缩放、字节序和恢复缓冲 |
| src-tauri/src/kinematics.rs | 不可变模型/TCP、显式输入的 FK/Jacobian、候选局部步与诊断 | 7R 递推、加权/阻尼、内部矩阵；不持有持续动作目标 |
| src-tauri/src/server.rs | HTTP/WS、序列化、会话与请求映射 | 网络连接与慢消费者处理；日志查询移交 spawn_blocking |
| src-tauri/src/journal.rs | SQLite 结构化事件、只读查询与原子统计 | 有界 try_send、专用 writer、事务/重试/保留与 checkpoint |
| src/App.tsx、PanelLayout.tsx、RobotScene.tsx、api.ts | 工作台、面板尺寸、三维渲染、单一本机客户端 | 布局交互集中在一个模块；不拥有设备运动状态 |

同一 Rust 应用里，串口与控制用专用线程，网络使用异步运行时，渲染在 WebView。命令交接有界，状态发送采用最新快照；慢 UI/订阅者不能阻塞电机循环。

arm 独占求解 seed、上个已接受参考和当前目标。kinematics 只计算候选及诊断，由 arm 复核当前反馈、限制、输入和控制权后提交；不让数值模块单独推进另一份动作状态。

普通命令超出容量时明确拒绝；连续输入只保留最新有效序号，停止/退出必须优先送达，不能排在大量旧输入之后。具体通道类型属于 arm 内部实现，不建通用总线框架。

停止在每个控制周期开始、每次 I/O 返回后、候选提交前检查。单次读写和完整报文事务各设时间预算；短写保留帧内偏移，超时/失败进入恢复或故障，不能盲重发整帧，也不能在半帧中插入其它报文。优先通道本身不能中断阻塞 I/O，时间预算不能保证解除卡死的 OS 调用。

官方模型和标定按左右臂集中打包，带来源信息；前端和后端消费同一份 resources 资源。端口使用枚举/配置，资源使用平台无关路径。当前只支持已提供模型，不增加设备注册或多后端机制。

SQLite 记录连接、控制权、动作、故障及应用事件，不逐帧存储串口或遥测，不记录 token 或 lease。`log` 只进行字段有界的内存记录和有界队列 `try_send`；`stats` 只读原子计数，不等待队列、磁盘、SQLite busy 或 writer。writer 独占写连接，初始打开和建表也在后台，采用 WAL、批量事务、有限 busy_timeout 和失败退避恢复。队列满增加 dropped，后台操作失败增加 errors，pending 包含已接收但未提交的事件，written 统计本进程成功提交的事件。

保留最近 100000 条事件，清理和 checkpoint 均在 writer 执行。`recent` 是阻塞只读接口，server 必须使用 spawn_blocking；按 id 降序、limit 最多 500。`shutdown(timeout)` 仅供应用关闭协调线程有界等待，超时返回失败并请求后台停止；不承诺强制中断 OS 调用，Drop 不阻塞。

## 6. 本机接口 v1

默认仅绑定 `127.0.0.1:8177`；绑定失败应在界面说明并禁用设备操作，不静默改成局域网监听。端口号是应用默认值，不是硬件参数。

| 入口 | 当前用途 | 返回的语义 |
|---|---|---|
| GET /v1/ports | 端口列表和可得的设备信息 | 只读，不打开或使能设备 |
| GET /v1/state | 完整权威快照 | 当前状态，不用查询成功推断设备健康 |
| POST /v1/control | acquire / renew / release | 控制模块决定后返回结果；控制者获得私有租约凭据 |
| POST /v1/commands | connect / disconnect / enable / disable / clear_fault / configure_tcp / jog_start / jog_update / step / stop | 请求入队不等于被控制器接受或设备执行完成 |
| GET /v1/logs?limit=50 | 最近结构化事件 | 按 id 降序，最多 500 条；阻塞读通过 spawn_blocking 执行 |
| WS /v1/events | 完整快照，包含请求结果和日志统计 | 首帧认证后发送状态；掉线后重取快照，不重放运动 |

本机接口使用当前应用会话凭据，控制请求还需有效的私有租约。只读快照只公开控制者标识与有效性，不广播可用于接管的租约凭据。CORS/Origin 不能替代控制权校验；接口信息可查看/复制，凭据不进入日志。

工作台总停止通过可信宿主入口调用同一 arm 取消操作，不依赖工作台持有运动租约。外部 HTTP 客户端不能自报“宿主”取得此权限；外部只读客户端保持只读，持有者可通过命令接口停止自己的动作。

HTTP 在请求头中携带应用会话凭据；WebSocket 升级后首帧认证，认证成功前不发送快照，认证等待有时限且连接数有界。凭据不进入 URL。浏览器 Origin 白名单与应用凭据分别检查，不用其中一项替代另一项；不建立用户账户系统。

租约期限由 arm 的单调时钟裁决，时长与续期间隔是明确配置。释放或到期时同时取消动作并推进 generation；迟到续租不能复活旧租约。控制线程应用命令与提交运动候选前，必须复核租约及 generation。

首版通过旧持有者 release、另一客户端 acquire 显式交接；持有期间拒绝他人的 acquire。先结束旧动作的控制流程，才允许新持有者发起运动。工作台聚焦、重连或点击点动都不能隐式取回控制权。

### 状态与命令的最小数据契约

| 数据 | 必需信息 |
|---|---|
| 上下文 | side、port、TCP 配置状态、控制者、generation、快照序号 |
| 实测关节 | 固定七个关节的名称/ID、q/dq/tau、逐关节 age_ms、可得的温度/电压/error；无反馈字段为 null |
| 反馈计算 TCP | 当前关节快照经当前模型/TCP 的 FK 结果；TCP 未配置或无有效完整反馈时为 null，四元数为 x/y/z/w |
| 动作 | space、mode、axis、request_id、progress；last_result 与有限 results 保存请求结果和原因 |
| 请求 | request_id、客户端标识、必要租约、预期 generation、动作空间和专用参数 |
| 连续输入 | jog_start 给出 space/axis/direction/speed/frame；jog_update 仅用 action_id/input_seq/ttl_ms 续期现有动作 |
| 日志统计 | pending、written、dropped、errors、healthy，控制线程只读原子值 |

generation 在连接重建、模式/TCP 改变、停止、动作完成、控制权失效等上下文变化时推进。input_seq 按租约、generation 和当前动作校验；续输入只更新显式开始的当前动作，不能隐式创建动作。快照序号只表示观测顺序，不代替上述上下文。

连续输入的截止时间在后端首次接收时用单调时钟确定，排队、重试和出队均不延长；每周期先处理取消，再计算和最终复核候选。停止后迟到的旧输入不能重新启动动作。

age_ms 由后端单调时钟计算；前端叠加接收后经过的时间作过期显示。关节接收时间跨度只描述主机收到反馈的情况，不表示七轴同步采样。反馈计算 TCP 来自当前关节快照与当前模型/TCP，不是独立 TCP 传感器的实测值。

POST /v1/commands 只先返回入队结果。accepted 指控制线程复核后建立该动作；rejected 指未建立。末端步长 completed 要求段结束，且新鲜反馈的 FK 结果在位置/角度容差内；关节步长以实测关节误差容差判定。写串口或 flush 成功都不能代替完成判据。连续动作由取消或失败结束，不把松开等同于“已停稳”。

已接受动作遇停止、换代或故障时，产生关联原 request_id 的 cancelled/failed 终态。步长在当前会话/generation 内至多执行一次；完成或取消后推进 generation，并保留有限最近结果供查询。迟到重复请求不能重启旧动作；不承诺跨进程重启的 exactly-once。超时或重连后查询状态，不自动重复发送旧运动。

错误至少区分参数无效、非控制者、上下文过期、设备未就绪、反馈过期、运动忙、队列满、数值无法继续、应用关闭中。错误包含原因与请求关联，不把所有失败都化成网络错误。

### 集中配置与验证的参数

UI 初始步长可用 1 mm / 1° 作为待测试的操作默认；它们不是实机精度或安全保证。设备配置集中给出线/角速度、关节速度与加减速、最大局部增量、位置/角度容差、参考相对实测的偏差、反馈年龄/接收跨度、输入有效期、租期、I/O/退出预算、控制周期与阻尼/奇异尺度。配置必须有限、单位明确且内部一致；不能用无穷大、缺失值或 parser 默认代替动态限制。

协议默认波特率为 6 Mbps，实际串口与转接器是否支持仍需实机确认。本规格固定参数类别、单位和失败行为；当前配置按模型和报文预算实现，其软件检查记录见实施状态。缺少某动作必需的有效配置时禁止该动作。真实可用范围仍由实机验证，不能因 Agent 编码完成而标通过。

## 7. 退出行为

关闭主窗口时，后端进入关闭中，停止接单，撤销控制权并使旧输入失效，取消当前动作并尝试执行设备退出策略。正常路径回收串口和控制线程，再结束本机接口与应用。当前动作即使由外部服务发起，也随应用退出取消。

设备无响应或 OS I/O 异常时，界面/诊断记录失败或未知，不报告“机械臂已停稳”。退出不无限等待 flush 或 join；超过已配置宽限期时记录设备结果未知并结束进程，不能同时报告线程已回收或输出已排空。具体预算在实现/验证中固定，软件退出上限不能当作物理停稳时限。

## 8. 运行与软件验证

当前环境为 macOS arm64。准备 Node.js/npm、Rust 和 Xcode Command Line Tools 后，在仓库根目录运行：

```bash
npm ci
npm run tauri dev
```

当前 macOS 应用构建使用 `npm run tauri -- build --bundles app`，未指定额外 Cargo target 或输出目录时，预期产物为 `src-tauri/target/release/bundle/macos/R1-7a Controller.app`。`npm run build` 只检查并构建前端，不能代替 Tauri 应用构建。具体命令结果、测试数量、产物及验收证据由[实施状态](implementation-status.md)维护。

# 低速稳定性校准：操作与测试

2026-11-22。控制页点击“校准”，再点击“开始校准”。测试以开始时的保持目标为原位，不移动到预设零位。Kp/Kd 固定，自动比较平滑摩擦与速度前馈。

## 一次测试做什么

1. 依次测 J1..J7，每轴在原位 ±2° 往返并返回原位，速度上限分 1°/s、2°/s 两档。
2. 选择误差较大的两轴，分别试验 Fc=0.1 Nm、Fc=0.2 Nm 和起始速度前馈的 75%。
3. 合并优选参数，再对全部已测轴执行相同程序。
4. 回到原位、恢复起始参数，显示曲线和比较结果。有推荐时点击“应用推荐”才应用。

开始前只需连接、使能、取得控制权并结束其他动作。没有额外的静止观察阶段，不以原始速度波动拒绝开始。程序将参考和实测各轴限制在起始姿态 ±4°，控制页不要求填写试验参数。试验区域需留出这些小幅运动的空间。

“停止”取消剩余动作，按原有轨迹约束减速并恢复参数，不继续回原位。停止、控制权过期、失能、断开和设备故障都能结束本轮。关闭弹窗后可重新查看；Esc 请求停止并关闭。

## 看哪些数据

弹窗按轴查看位置、速度与跟随误差，可查看整个测试、单轮试验或同轴的前后对照。全程中即使另一轴在运动，仍能查看当前所选轴的波动。

- 控制参考：控制器生成的七轴位置。
- 成功发送：最近已完整写入串口的七轴目标及未缩放轨迹速度。
- 实测反馈：原始回传位置、速度，另记录每轴反馈年龄。

每 20 ms 记录一次，最多 90000 点。曲线时间为主机相对时间，成功发送另带完成时刻。新报告保存完整时间序列；导入旧报告只有统计时，显示每轮指标，不生成时间曲线。

位置误差与速度误差分开展示。候选用相对基线的速度误差（0.6）及位置误差（0.4）综合比较，再进行合并参数复测。没有固定的 15% 改善门槛；没有改善也是完成的测量，不显示为运行失败。

用户提供的 J4 报告包含四轮完整统计，旧判定结果为 unchanged。Fc=0.2 Nm 时位置跟随 RMS 从约 0.339° 降到 0.209°，下降约 38%；速度 RMS 仅降低约 1.3%。这说明位置与速度需要分别查看，不能由一个速度百分比概括。原文件没有时间序列，无法据此判断具体抖动频率。

## 收纳完成

保持连接的返回在参考轨迹到位、指令减速结束后完成。到位断开另要求七轴位置距目标不超过 0.02 rad（约 1.15°），并有覆盖 200 ms 的新反馈。两种返回均不检查实测 dq 是否归零。

实际位置仍未到时不释放保持力；到位断开超时会显示具体关节与角度。按停止后不会再执行原先计划的断开。

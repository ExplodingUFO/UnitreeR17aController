# 低速稳定性校准：操作与测试

2026-11-22。这项测试比较**平滑摩擦补偿与速度前馈**，Kp/Kd 保持当前值。它通过相同动作的前后记录比较跟随表现。

## 操作

1. 控制页打开“校准”，生成运动预览。默认根据当前姿态与 TCP 计算基座 XYZ 各方向的连续可达行程；也可指定正的单向幅度与速度。
2. 选择 X、Y、Z 或关节阶段，查看彩色路线、方向、距离、关键姿态与肘腕扫掠；用俯视、正视、侧视核对占用空间，再播放或拖动动作。关节试验为七轴分别 ±8°，范围盒可单独打开。
3. 确认周围空间后开始。程序依次测末端基线、七轴基线、参数候选，最后重跑同一条末端路线。
4. 完成后回原位、恢复起始参数。查看七轴位置/速度对照及具体参数变化，点击“应用推荐”才采用结果。

预览使用当前保持指令与 TCP，计算在工作线程执行，不发送设备命令。运动开始后沿用现有速度、加速度、jerk、停止和设备故障处理，不增加速度噪声或位置静止观察门槛。

“停止”取消剩余动作，减速并恢复参数，不再自动回原位。关闭弹窗后可重新查看；Esc 请求停止并关闭。

## 比较哪些参数

- 每轴关节试验为原位 ±8°、2°/s 与 4°/s 两档往返。
- 在跟随误差较大的两轴分别尝试 Fc=0.1 Nm、Fc=0.2 Nm，以及起始速度前馈的 75%。Kd 不参与搜索。
- 合并优选参数后重复末端路线，比较全部七轴的跟随 RMS、速度 RMS 和位置峰值。
- 结果列出各参数的原值与推荐值，不把一个综合百分比当成所有关节都已改善。没有改善也正常完成，保留数据。

纯关节 API 模式仍可独立使用；有末端路线时以末端前后对照作为最终复测，减少重复的逐轴复测。

## 曲线和保存

每 20 ms 保存七轴控制参考、成功发送目标、原始实测位置/速度、反馈年龄及发送时刻，最多 90000 点。速度误差用实际 100 ms 位移窗口计算。可查看整个测试、单轮和末端前后对照；选 J2 时也能看到其他关节运动期间 J2 的响应。

长记录绘图保留各轴位置与速度误差的极值，再补均匀采样点，避免缩略时恰好跳过抖动峰值。下载 JSON 始终包含全部原始点。旧报告没有时间序列时显示统计，不生成曲线。

完成状态发布前，完整报告已保留在本机内存，立即支持详情与下载。中途停止也保留已采集的曲线和当前轮统计。SQLite 的编码与写入异步进行，元数据和曲线同事务保存，保留最近 100 份；重启后从数据库读取。

## 这轮测试解决了什么

| 场景 | 实际验证 |
| --- | --- |
| 完成却显示记录不存在 | 用真实控制流程完成测试，同时锁住 SQLite 写事务；旧版详情返回 404，新版详情、下载与历史均可读。解除锁、关闭并重新打开后，从新服务读回完整曲线。 |
| 预览是否偷偷发动作 | 通过实际 HTTP 接口请求预览，确认控制动作和 generation 不变。 |
| 预览和执行是否相符 | 用当前采样起姿和带偏移 TCP 的姿态执行生成程序，比较实际参考的 XYZ 行程、TCP 方向与模型关节范围，同时检查七轴曲线、回原位及参数恢复。 |
| 采样中的发送误停 | 回放 1,388 个记录点；旧检查在 35.749 秒因 0.050129 mm 的横向残差拒绝发送，移除重复检查后可继续取样。 |
| 包络是否只覆盖工具点 | 几何测试核对左右臂、偏移 TCP、关节 ±8° 与末态回原位，所有预览点以 FK 核对。 |
| 曲线是否藏掉波动 | 在非运动轴注入位置/速度峰值，原等间隔抽取会漏掉，新绘图抽取保留这些真实采样点。 |
| 停止与现有运动 | 继续运行原有取消、失去控制权、故障、TCP、停止和收纳回归，未另建串口控制路径。 |

这些测试使用实际 Rust 模块、HTTP 服务、SQLite 和可控反馈，不连接真实设备。界面另外检查预览、确认、参数变化、旧报告、曲线与历史在 800×560 和宽屏的操作。字段见 [API 说明](implementation-contract.md#510-低速稳定性校准)。本轮新运动范围与减抖效果尚未真机验证。

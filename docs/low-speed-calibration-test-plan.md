# 低速稳定性校准：实现与试用测试

2026-11-22。首版对选定关节执行有限往返，自动比较摩擦及速度前馈候选，固定全部 Kp/Kd。已有 TCP 路径、停止与收纳继续使用原实现。本轮先完成离线与模拟设备验证，真实机械臂由使用者启动试用。

## 测试入口与范围

- `calibrate_start`：通过现有命令接口启动，输入 `settings:{axis,excursion,speed,max_friction}`，全部使用 SI。axis 为 0..6；excursion 是允许的相对位移范围，测试目标取其一半，为起停保留空间。
- `calibrate_apply`：输入 `calibration_id`，只应用本次连接、同一工具上下文和起始配置下经重复验证的推荐值。
- `stop`、桌面停止、控制权过期、失能、断开、故障、退出：终止校准，取消剩余测试。正常取消减速到静止后恢复起始参数，故障不自动重新使能。
- `Snapshot.calibration`：包含任务、阶段、试验/片段进度及最终报告；任务存在时对外显示 calibration 动作，其他运动与参数修改互斥。
- `GET /v1/calibrations` 与 `GET /v1/calibrations/{id}`：读取异步保存的报告，重启后仍可查阅。历史报告不直接获得新连接的应用资格。

界面入口是控制页参数弹窗内的“低速校准”；设置、进度和结果位于同一个二级弹窗，适配 800×560。关闭弹窗不结束校准，停止和 Esc 结束校准。报告与事件由后台写入 SQLite。首版报告保存各轮窗口统计、配置和结论，保留最近 100 份；逐帧数据沿用已有短时录制入口，未加入 IMU 或输入整形。

## 先写行为测试，再逐项实现

| 范围 | 必须验证的行为 |
| --- | --- |
| 输入 | 非有限值、错轴、位移/速度/补偿上限越界被拒绝；没有控制权、使能或有效反馈不能启动 |
| 候选 | Kd 和未选轴的有效行为保持原样；Coulomb 与速度前馈分别试验；不同时搜索 B 与速度前馈；全局摩擦开关不能意外启用其他轴的休眠系数 |
| 测试轨迹 | 起点来自稳定发送参考；有限往返，两档速度；目标、参考与实测均检查范围；每段有时间上限；轨迹保持原有速度/加速度/jerk 约束 |
| 测量 | 用新到达的位置与发送参考的固定时间窗比较；不对微秒级接收间隔求导、不跨长缺口；停驻/起停不计入稳态窗口；无有效数据不生成推荐 |
| 优选 | 候选需同时改善速度跟随、保持位置与其他轴表现；基线与候选重复验证；无改善、基线漂移或数据不足时推荐为空；速度目标不随前馈权重缩小 |
| 中止 | 每个片段、换参数、复测、恢复阶段都能停止；释放控制权后不继续动作；故障不恢复使能；迟到请求不能重启已中止任务 |
| 应用 | 完成后先恢复基线；显式应用推荐才改变配置；拒绝过期连接、工具/配置变化、超出测试姿态和没有推荐的结果 |
| 持久化 | 报告经正常关闭重开可读；忙数据库、队列饱和及关闭不阻塞生产者；未入队报告保留补投，控制结束后交接退出补投；报告写入不改变事件日志的统计含义 |
| UI | 请求入队与实际接受分别处理；不重复启动；状态断开/重连、迟到响应、429 明确拒绝后手动重试、网络超时继续观察、历史查看、停止和焦点循环；800×560 与宽屏完整可操作 |

数值测试使用已知的平滑、量化、停滞追赶和无改善序列。控制测试使用可控时钟与测试串口，不访问真实串口或 8177。完成实现后由独立代码审查检查状态转换、时间、参数恢复、控制权与数据质量；修复发现后再执行受影响的回归。

## 真机首次试用

1. 固定机械臂与当前工具，选择一个关节，示教测试中心并检查往返区域。
2. 确认起始参数与输入的相对范围、速度、补偿试验上限，再启动校准。
3. 在首轮基线期间试一次停止，确认任务终止、保持状态和参数恢复。
4. 再运行完整校准，检查报告中的样本、基线重复性、推荐和各项误差。
5. 有推荐时使用结果，分别检查关节点动、末端平移/绕 TCP 旋转、停止与收纳。
6. 保存前后记录。真实减抖、负载变化及长时间稳定性分别验收。

软件输入上限用于限制本次实现，不视为本体已验证的试验范围。首版的推荐仅适用于本轮测试上下文；它不代表整个工作空间已完成标定。

## 已执行的软件验证

- Rust 全量：193 项库测试、7 项 CLI 测试通过，另 1 项私有采样回放默认忽略。使用 `cargo test --manifest-path src-tauri/Cargo.toml --all-targets --locked -- --test-threads=1` 逐项运行；串口测试包含主机计时，与浏览器检查分开执行，不放宽原断言。
- 参数边界：J1/J7 × 1°/10° × 0.005/0.04 rad/s 的完整基线往返，检查参考范围和离散速度、加速度、jerk；短程五次轨迹已补充 jerk 时长下限。
- 时间配对：RX 只能选择主机已成功写完整批的 TX；没有合法参考时中断统计窗。
- 取消与恢复：停止、释放、控制权过期、失能、断开和故障取消后不执行后续片段；退出前交接尚待入队的报告。
- 上下文：TCP A→B→A、重复应用及参数版本变化使旧报告失去应用资格。
- UI：校准集成 10 项、HTTP 拒绝/网络异常 6 项、参数弹窗 27 项及录制/历史日志 10 项模拟检查通过；前端格式、TypeScript/Vite 与 macOS arm64 `.app` 打包通过。
- 持久化：确定性持有报告队列锁，在校准完成后下一周期重试，以及立即关闭交接两种情况下，正常重开均可读回报告。

这些检查使用计算序列、测试串口和模拟响应；真实机械臂的低速表现、停止距离、工具与负载适应性仍待试用记录验证。

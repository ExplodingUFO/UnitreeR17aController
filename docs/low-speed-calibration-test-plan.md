# 低速摩擦辨识校准：操作与测试

2026-11-23。本轮通过逐轴双向多速度采样辨识 Stribeck 曲线，再用相同动作的前后记录比较补偿效果。Kp、Kd 和速度前馈权重保持开始时的值。

## 操作

1. 控制页打开“校准”，生成运动预览。默认根据当前姿态与 TCP 计算基座 XYZ 各方向的连续可达行程；也可指定正的单向幅度与速度。
2. 选择 X、Y、Z 或关节阶段，查看彩色路线、方向、距离、关键姿态与肘腕扫掠；用俯视、正视、侧视核对占用空间，再播放或拖动动作。默认关节试验为七轴分别 ±8°，范围盒可单独打开。
3. 确认周围空间后开始。程序依次测末端基线、逐轴双向多速度基线；进入“辨识中”（`identifying`）后在后台拟合，再测试各轴的有效拟合候选。
4. 合并各轴优选参数，重跑同一条末端路线；纯关节模式使用合并参数逐轴复测。正常完成回原位，恢复开始前的伺服与运动设置。
5. 查看逐轴正负曲线、参数原值与推荐值、七轴位置/速度前后对照，点击“应用推荐”才采用结果。在伺服参数中可按轴切换 Stribeck，全局摩擦开关控制摩擦输出。

预览按当前保持位置和 TCP 在后台生成定时轨迹。确认后控制线程和串口按各自的时间取同一条曲线上的关节位置与速度。界面显示所选 XYZ 往返一轮的计划用时。运动沿用现有速度、加速度、jerk、停止和设备故障处理。“停止”取消剩余动作，减速并恢复参数，不再自动回原位。关闭弹窗后可重新查看；Esc 请求停止并关闭。

## 试验设置与辨识结果

- `speed` 默认 2°/s。可选 `speeds` 以 rad/s 提交；缺失或 `[]` 时使用 `speed/2、speed、2×speed`，默认即 1/2/4°/s。显式速度必须为有限正数，不另加速度或档数上限；实际执行仍受当前运动设置与模型约束。
- `max_friction` 缺失或为 null 时，按各轴有效样本中 `abs(反馈扭矩−URDF模型重力)` 的峰值自动确定。可指定非负有限 Nm 上限；0 不生成补偿候选。它与每轴伺服配置的 0.5 Nm 基线是不同设置。
- 每个所选轴分别拟合正负方向的 Fc、Fs、B、Vs，并同时拟合加速度项 `inertia*a` 分离加速段影响。有效候选均参加比较，不使用固定 Fc=0.1/0.2 Nm、75% 速度前馈或只挑两轴的搜索。
- 无法辨识的方向显示无结果并沿用起始补偿模型；已辨识方向仍参加比较。两方向均无结果时该轴保留起始配置，其他轴继续完成。没有改善时正常结束并保留数据。
- 最终推荐以合并参数的末端或关节复测为准，列出具体参数变化和各轴指标，不用一个综合百分比替代全部比较。

拟合来源 `feedback_effort_residual` 是原始反馈扭矩减实际反馈位置处 URDF 模型重力的经验残差；加速度系数不作为补偿下发。这些结果不等同于独立测得的摩擦力矩、真实等效刚度或已验证的物理惯量。重力计算、加速度估计与拟合均由后台 Rust 计算完成，控制线程不等待日志或 SQLite。

`report.identification` 缺失时按 `[]` 读取。每轴记录 axis、source、samples、positive/negative、inertia、max_friction，后者是实际使用的预算值。每个方向记录曲线、样本数、有符号实测速度范围、加权模型残差 RMSE，以及 velocity/effort/predicted/samples 绘图点。velocity、effort、predicted 均保留方向符号；predicted 为未截断摩擦模型加惯性项的加权均值；补偿幅值只影响实际输出，不参与辨识截断，RMSE 与位置/速度跟随 RMS 分别报告。速度为 rad/s，力矩与 RMSE 为 Nm，黏性系数为 Nm·s/rad，inertia 为 kg·m²。

## 曲线和保存

每 20 ms 保存七轴控制参考、成功发送目标、原始实测位置/速度、反馈年龄及发送时刻，在 90000 点的内存空间中保留全程样本。新增可省略的 `effort` 为七轴原始反馈扭矩；重力在后台按实际反馈关节位置和 URDF 计算。旧报告缺失 effort 时按 null 读取。速度误差用实际 100 ms 位移窗口计算。

可查看整个测试、单轮和末端前后对照；选 J2 时也能看到其他关节运动期间 J2 的响应。详情绘图从已保留点中提取各轴位置与速度误差的极值，再补均匀采样点。下载 JSON 包含全部保留点；旧报告没有时间序列时仅显示统计。旧六字段伺服配置省略 `stribeck` 时按关闭读取，仍可导入。

录制按试验组分配内存中的采样空间；超过单组份额后采用保留端点的真实样本抽取，覆盖全部关节、方向、速度和最终复测，不在录满时停止采集。报告 `captured_samples` 为全程采集次数，`sample_count` 为保留的曲线点数；两者不同时界面显示两项。辨识样本按关节和运动片段分别抽取，同时保留原始前后邻帧的时间与速度；后台用这些原始邻帧计算导数，不把抽样间隔当成原始反馈间隔。控制线程每次录制为常数时间，不排序、不序列化、不等待 SQLite。离线测试用较小采样空间覆盖七轴九片段和全部 21 组对比，检查每组起止点、后段数据及排序后的时间；另用 240 秒、100 Hz、1 Hz 速度波动验证抽样后的加速度依据及摩擦/惯性分离。

完成状态发布前，完整报告已保留在本机内存，立即支持详情与下载。中途停止也保留已采集的曲线和当前轮统计。SQLite 编码、写入与重试异步进行，元数据和曲线同事务保存，保留最近 100 份；重启后从数据库读取。

### 2026-11-23 发送偏差回归

981 点记录的首段为基座 +X，设定 10 mm/s。停止前，J7 的控制参考最高为 1.571 rad，串口发送位置最高为 1.62394 rad。把末次发送位置作为保持起点，可复现位置与导数条件无交集。报告没有逐个控制周期的加速度，无法由它还原故障前每一个周期。

自动测试保留该次的七轴起始角与 TCP，使用不等控制周期、独立发送取样，走完同一套 XYZ 调整前后试验。另可把 `R17A_CALIBRATION_REPORT` 指向完整报告，在 `src-tauri` 执行 `cargo test --release --lib replay_saved_program_at_recorded_send_times -- --ignored --nocapture`，用报告的发送时间逐点核对新计划。本次记录的九段 XYZ 路程合计 2.564 m，按 10 mm/s 请求速度规划后单轮约 6 分 17 秒。从该起姿密集采样，模型 TCP 的横向偏差峰值约 0.17 mm，速度峰值约 9.90 mm/s。实际跟随误差、振动以及周边设备间隙仍需真机验收。

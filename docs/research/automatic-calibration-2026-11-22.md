# R1-7a 自动校准与自适应参数方案

日期：2026-11-22。适用于当前 R1-7a 的 PD 与力矩前馈接口。以下为方法评估和建议流程。

**有自动整定方法；建议先做一键离线分析与参数候选，再做受控辨识；持续在线调参放在独立真机试验中验证。** 接口是 PD＋力矩前馈，无 Ki，不能直接套通用 PID 自动整定。

已知右臂底座向上、无载，当前 Kp60/Kd10、摩擦关闭、FF1。J2 指令约 0.031–0.042 rad/s，位置差分约 0.0008–0.082 rad/s、误差约 1.37°，提示粘滑/极限环，尚非定论。Kd15 时全臂曾失去保持力，触发故障未记录，不能归因于阻尼过大。官方遥操 60/10、90Hz 只是参考；IM6014 空载速度模式的保护数字不能套给 J2 的 IM6010。

## 方法适用性

- **继电整定：暂缓。** [Åström–Hägglund 原论文（1984）](https://lucris.lub.lu.se/ws/portalfiles/portal/6340936/8509157.pdf)通过继电反馈产生振荡，估计临界频率/增益。七轴耦合、重力、摩擦会污染单回路结果；已有失去保持力事件，不宜主动找振荡。未来也须限定姿态、单轴幅值和频带，记录振幅、周期、力矩与其他轴响应。
- **频响辨识：有条件适合。** 稳定保持下逐轴注入限幅正弦/多正弦，观察全七轴输出；跨姿态重复，不能把某姿态的单轴频响当全局模型。所得为固定 PD 下的闭环响应，不能当作裸对象频响。
- **模型式整定：后续候选生成器。** 辨识局部等效惯量、阻尼、延迟后，按目标带宽/阻尼生成保守 PD 候选，再验证耦合与饱和。[Swevers 等原论文（1996）](https://doi.org/10.1006/mssp.1996.0039)采用受运动约束的周期傅里叶轨迹改善辨识条件；实现应覆盖速度、加速度与姿态，而非只用一段慢速运动。

## 优先辨识什么

先拟合 `τ残差≈Fc·sgn(dq)+B·dq`。同姿态附近正反向、多档恒速段用于区分 Coulomb 与 viscous；多姿态双向逼近估重力残差（静止力矩混有静摩擦），受限加减速段估惯性残差。无载仍有连杆自重；底座方向须进入重力模型。

残差应以可信力矩减去已有重力/惯性预测构造，明确前馈与 PD 合力矩、限幅和单位；只有 τFF 不能当实测总力矩。参数相关性过强即拒绝出数。简单摩擦模型不覆盖零速预滑移、Stribeck 与滞回，[LuGre 原论文（1995）](https://lup.lub.lu.se/search/ws/files/6363840/8498924.pdf)说明了这些边界；先验证简单模型，不默认升级复杂补偿。

## 离线与持续自适应

离线可查时间戳/丢帧、位置差分与反馈速度一致性、误差及振荡频谱；激励和力矩足够时才能回归候选。现有窄速度日志不能唯一辨识摩擦、重力、惯量，不能证明新增益稳定，也失能原因还需要对应时刻的故障记录。

持续自适应会在运动中更新模型或控制量，必须另有激励、稳定性及限幅设计。[Slotine–Li 原论文（1987）](https://journals.sagepub.com/doi/10.1177/027836498700600303)是 PD 加完整动力学前馈的在线参数估计，不是按误差随意改 Kp/Kd。当前应采用固定参数的离线候选。

## 最小产品交互

1. **分析采样**：导入录制，核查七轴指令/反馈 q、dq、力矩、增益、采样/发送时间戳及故障/使能状态；缺项标明。
2. **候选与验证**：显示适用姿态、置信区间、回归秩/条件数及独立留出轨迹误差；证据不足不推荐参数，拟合好不等于真机稳定。
3. **真机引导试验**：仅在明确配置后开放；先查清失去保持力原因、验证支撑与停机策略，再配置关节、运动/力矩上限和中止条件。
4. **手动应用**：展示参数差异、版本与回退项；候选须另行确认应用，分析完成不自动写入。

纯 Rust 足够实现首版：选 [nalgebra 官方纯 Rust SVD/QR](https://www.nalgebra.rs/docs/user_guide/decompositions_and_lapack/)做小规模回归与秩检查，少量滤波、残差统计和离散频谱即可；数值工具不能替代激励与安全验证。当前软件提供录制、离线统计和手动参数调试，尚未实现自动辨识或自动整定。

# 从打印机共振校准借鉴什么

2026-11-22。以下事实已核对官方文档与源码；机器人适配部分是针对本项目的设计建议，尚未实机验证。

## 已有实现

Klipper 用加速度计记录测试响应，自动选择输入整形类型和频率；选型同时考虑振动残留与平滑代价。支持多个测量点或多份输入共同选型。[测量与自动校准](https://www.klipper3d.org/Measuring_Resonances.html)

输入整形通过构造运动命令来减少激发振动。不同整形器对频率误差的容忍度和动作平滑程度不同；机械或运动质量改变后需要重新核对。[原理与整形器取舍](https://www.klipper3d.org/Resonance_Compensation.html)

官方拟合程序在候选频率、阻尼条件和多组测量中估计残余响应，并结合平滑代价选型；这些是预测值，仍需实际验证。[shaper_calibrate.py](https://github.com/Klipper3d/klipper/blob/master/klippy/extras/shaper_calibrate.py)，本次读取 blob `75db6515aa062e40e0cc109b849f007e3bd68bec`。

不能把打印机的 X/Y 频率、默认阻尼或加速度数字直接作为机械臂参数。打印机的拟合目标与几何假设也不能代替机械臂的 TCP 路径及停止验收。

## 本项目适合的最小算法

先实现常见的正系数 ZVD 候选，再比较是否需要对频率变化更稳健的 EI 类方案。候选还必须满足可接受的响应延迟、运动时间、路径与停止约束。ZVD 的常见表达为：

```text
ωd = 2π fn sqrt(1-ζ²)
K = exp(-ζπ/sqrt(1-ζ²))
权重 A = [1, 2K, K²] / (1+K)²
延时 T = [0, π/ωd, 2π/ωd]
s_out(t) = Σ A[i] s_in(t-T[i])
```

fn 为模型自然频率，ζ 为阻尼比；频谱峰值不能无条件当作 fn。需要在有效频带内拟合，并在测量不确定范围内评价候选。系数归一化后的直流增益为 1；核的总长度与加权平均延时是两个量，都要记录。[官方定义供核对](https://github.com/Klipper3d/klipper/blob/master/klippy/extras/shaper_defs.py)，本次读取 blob `e7b62b3cb4507ea1ea7a3d63d5fe47edacb94a53`。

零振动导数约束提供频率误差附近的鲁棒性，不代表对整个工作空间都有效。机械臂的刚度、惯量、耦合和工具会随条件改变，需在选定姿态与负载范围内实测。

## 对当前控制器的适配

- 先标定低速摩擦/伺服响应，再单独测共振。持续同向运动的停滞后追赶，不能仅靠输入整形解释或消除。
- 有限直线或绕 TCP 的旋转优先整形公共路径进度，再由现有运动学生成关节参考。独立滤波七轴位置可能改变末端路径；公共进度也只是局部适配起点，最终七轴导数和 TCP 路径仍要检查。
- 当前外部发送为 10 ms 一批。其离散命令的理论 Nyquist 上限是 50 Hz，实际可用频带还受串口、执行延迟、驱动与约束影响；不把 50 Hz 当成可用扫频上限，也不复制打印机的扫频范围。
- 关节编码器适合测低频跟随，末端加速度计用于额外观察柔性振动。采样在传感器侧定时并带序号和时间戳；补偿坐标与重力影响后再分析。USB 或网络到达时间不能充当传感器采样时间。
- 正常完成应包含整形尾部；停止、输入过期和故障优先现有逻辑。停止时从已发送参考进入受限减速，不继续播放剩余校准动作。

运行算法可用 Rust 固定容量延时缓冲和现有 nalgebra 实现，拟合在后台计算，控制周期只取已验证配置和少量延时项。Klipper 源码采用 [GPLv3](https://github.com/Klipper3d/klipper/blob/master/COPYING)；本项目保留 BSD-3-Clause，拟实现采用公开方法自行编写，不把其源码直接移入。
